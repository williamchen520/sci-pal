# 工作计划：自适应与文献情报系统

> 状态：待评审  
> 范围：第 1 项（用户画像、每周简报、防信息茧房、算力调度、旧数据挂载、多用户权限）  
> 定位：课题组为主，兼容研究所规模。

## 1. 已确认决策

| 项 | 决策 |
|---|---|
| 用户单位 | 课题组为主，兼容研究所 |
| 频率 | 每周 |
| 来源 | PubMed / arXiv 等 |
| 入库 | 简报采用文章至少自动入库 metadata；OA 才抓 PDF/XML |
| 非 OA | 只存 metadata；用户可手动补 PDF |
| 画像 | 显式为主，用户掌握主动权 |
| 点击行为 | 只用于去重/已读，不自动改画像 |
| 呈现 | Web 优先；DSH 第一版打开 URL |
| 防茧房 | 默认 70/20/10，可关停；安全提示保留 |
| PPT | 第二阶段 |
| 旧数据 | 只读挂载 + 索引；默认 private；必须提示备份 |
| 算力 | 本地 / 超算 / 云端按数据等级 |
| PI 权限 | 不看成员画像和简报；平等原则 |

## 2. 目标

1. 每周为每个启用画像的用户生成一份文献简报；
2. 5 条精读 + 15 条浏览；
3. 显式画像驱动，用户可编辑；
4. 默认 70% 核心 / 20% 相邻 / 10% 探索；
5. 简报私有，PI 不可见；
6. 旧数据可只读挂载并索引；
7. 1000 账号、100 并发下可运行；
8. 私有数据不出实验室网络。

## 3. 非目标

- 实时推送；
- 自动替用户改兴趣；
- PI 监控成员阅读；
- 第一版做 PPT；
- 第一版做跨实验室共享；
- 第一版做自动 PDF 全文抓取（非 OA）。

## 4. 总体流程

```
每周定时
→ 读取启用画像
→ 生成检索式
→ PubMed / arXiv 拉新
→ metadata 入库
→ 去重 / 相关度 / 新颖性排序
→ 70/20/10 配额
→ 生成简报
→ Web 展示
→ DSH 打开 URL
→ 用户反馈
```

## 5. 用户画像

### 5.1 字段

```yaml
topics: []            # 主题关键词
methods: []           # 方法关键词
journals: []          # 关注期刊
authors: []           # 关注作者
seed_papers: []       # 种子论文
exclude_terms: []     # 排除词
domain_packs: []      # 领域包
language: zh          # 简报语言
exploration: 0.1      # 探索比例
enabled: true
```

### 5.2 编辑

- Web 编辑；
- 支持从种子论文提取关键词；
- 支持导入 BibTeX/DOI；
- 支持预览检索式；
- 支持重置。

### 5.3 不自动改画像

点击/收藏/忽略：

- 只记录为 `read/ignored/saved`；
- 用于去重和“已读不重复”；
- 不自动加入 topics；
- 用户可手动“加入画像”。

### 5.4 项目画像

- 一个用户一个主画像；
- 可选多个项目画像；
- 周报默认用主画像；
- 项目画像可单独生成。

## 6. 来源与入库

### 6.1 来源

- PubMed E-utilities；
- arXiv API；
- 可选 Europe PMC / bioRxiv / medRxiv；
- 后续可加期刊 RSS。

### 6.2 检索式

系统生成：

```
(topics OR methods OR seed_paper_terms)
AND (date_range = last 7 days)
NOT exclude_terms
```

用户可预览/编辑后保存。

### 6.3 入库策略

被简报采用的文章：

- 必须入库 metadata；
- 已发表 → 全局 `public` 库；
- 预印本/未发表 → 按 workspace 规则，默认 `internal`；
- OA → 尝试抓 PDF/XML；
- 非 OA → 只存 metadata；
- 用户可手动补 PDF。

### 6.4 去重

优先级：

1. DOI；
2. PMID；
3. arXiv ID；
4. 标题 + 第一作者 + 年份；
5. 文件 hash。

## 7. 简报格式

### 7.1 数量

默认：

```
5 条精读
15 条浏览
```

用户可调：

```
精读 3–10
浏览 10–30
```

### 7.2 每条字段

```json
{
  "title": "...",
  "journal": "...",
  "date": "2026-10-30",
  "doi": "...",
  "summary": "...",
  "why_relevant": "...",
  "key_finding": "...",
  "evidence": "...",
  "url": "...",
  "category": "core | adjacent | explore",
  "confidence": 0.0
}
```

### 7.3 分组

```
本周必读（5）
值得浏览（15）
探索/争议（10% 配额内）
已读/忽略
```

### 7.4 手动调整

- 加入本期；
- 移除；
- 标记已读；
- 收藏；
- 加入画像；
- 反馈“不相关”。

## 8. 排序与 70/20/10

### 8.1 分数

```
score = 0.5 * profile_match
      + 0.2 * recency
      + 0.2 * novelty
      + 0.1 * source_quality
```

### 8.2 分类

| 类别 | 判定 |
|---|---|
| core | 命中主画像主题/方法 |
| adjacent | 同领域包不同主题 |
| explore | 跨领域包/争议/阴性结果 |

### 8.3 配额

```
70% core
20% adjacent
10% explore
```

用户可：

- 调整比例；
- 关停 explore；
- 但安全提示保留：
  - 撤稿；
  - 更正；
  - 重大阴性结果。

## 9. 防信息茧房

### 9.1 机制

- 主题多样性；
- 来源多样性；
- 观点/结论冲突提示；
- 阴性结果；
- 跨领域探索；
- 预印本/同行评审标识。

### 9.2 指标

- 主题熵；
- 来源多样性；
- 新颖性；
- 跨领域比例；
- 收藏率；
- 忽略率；
- 用户主观评分。

### 9.3 原则

```
多样性不能以不相关为代价
```

探索条目单独标注，不混入“必读”。

## 10. 算力与闲时调度

### 10.1 队列

```
interactive > weekly_brief > indexing > backfill
```

### 10.2 任务

- metadata 抓取；
- PDF/XML 解析；
- 句子切分；
- embedding；
- 简报生成；
- 旧数据索引。

### 10.3 闲时

- 夜间；
- GPU 空闲；
- 无交互请求；
- 手动触发。

### 10.4 资源

- 本地 GPU；
- 超算 GPU；
- 云端仅 public；
- 每 workspace 配额；
- 失败重试；
- 超时降级。

### 10.5 周报生成

- 只给 `enabled=true` 且画像完整的用户；
- 分批生成；
- 失败可重试；
- 生成时间窗口内完成。

## 11. 旧数据挂载

### 11.1 方式

只读挂载：

```text
/mounts/legacy/<name>   ro
```

不直接改旧库。

### 11.2 流程

1. 选择旧库/目录；
2. 提示备份；
3. 选择 `data_class`，默认 private；
4. 只读挂载；
5. 建索引；
6. 可搜索/引用/生成简报；
7. 不写回旧库。

### 11.3 旧库适配

- 旧 `research.db`；
- PDF 目录；
- BibTeX/RIS；
- 其他系统导出。

### 11.4 权限

- 挂载者拥有；
- 默认 private；
- 可显式共享到 workspace；
- PI 不可见 private。

## 12. 权限与隐私

- 画像：仅本人可见；
- 简报：仅本人可见；
- PI 不可见成员画像/简报；
- 管理员不可见内容；
- 点击行为仅本人和聚合统计；
- 聚合统计不暴露个人。

## 13. Web 与 DSH

### 第一版

```

```

### 第二版

```

```

### 访问

- 登录；
- token；
- workspace 权限；
- 不公开 URL。

## 14. 数据模型


## 16. 评测

### 简报质量

- 5 条精读人工评分 ≥ 4/5；
- 相关度；
- 新颖性；
- 来源多样性；
- 70/20/10 合规；
- 隐私零泄露。

### 系统

- 每周任务在窗口内完成；
- 1000 账号分批；
- 100 并发；
- 失败重试；
- 索引不阻塞交互。

## 18. 验收

- 周报按时生成；
- 5+15 条；
- 70/20/10 可配置；
- 点击不自动改画像；
- PI 看不到成员画像/简报；
- 非 OA 只有 metadata；
