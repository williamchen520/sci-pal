# 架构变更授权：P7 客户端入库追踪

> 日期：2026-11-08  
> 状态：**待人类批准修改**  
> 规则：`.dsh_rules` 规则 0A  
> 前置：P6

---

## 1. 问题

客户端入库追踪插件已存在，但默认关闭：

```text
SCIPAL_INGEST_TRACKING 未设置
插件不建表
不注册路由
```

结果：

```text
客户端导入没有 batch/item/finding
papers.quality_status 无法追踪
```

---

## 2. 变更

启用：

```text
SCIPAL_INGEST_TRACKING=1
```

连接：

```text
plugins/ingest_tracking/store.py
  pg_connection -> admin_connection
```

新增 6 条只读/写入路由：

```text
POST /api/ingest-tracking/batches
GET  /api/ingest-tracking/batches/<batch_id>
POST /api/ingest-tracking/batches/<batch_id>/items
POST /api/ingest-tracking/batches/<batch_id>/finish
GET  /api/ingest-tracking/papers/<paper_id>
POST /api/ingest-tracking/papers/<paper_id>/review
```

修改 `ARCHITECTURE.json`：

```text
api.endpoints  186 -> 192
路由键         204 -> 210
```

---

## 3. 理由

```text
客户端导入需要可追溯
batch -> item -> finding
quality_status 可人工复核
```

原则：

```text
只标记，不裁决
不删除输入
不阻塞整批
后端批量导入不调用
```

---

## 4. 影响

```text
新增 3 张表（首次启用时）
papers 增加 quality 字段（已有迁移）
新增 6 条路由
只写 public 管理面，不写租户
```

---

## 5. 迁移

```text
1. 设置 SCIPAL_INGEST_TRACKING=1
2. 启动时 ensure_schema
3. 重启 app
4. 客户端按 batch/item 调用
```

回滚：

```text
取消环境变量
重启 app
表保留，不删数据
```
