> 日期：2026-11-08  
> 状态：计划稿，允许根据实测调整  
> 原则：先定契约，再回填，再联邦，再评测，最后插件/产品

---

## 0. 总体判断

```text
当前不是“缺功能”
而是“缺稳定的数据坐标系”
```

因此顺序不是：

```text
300 题 -> GraphRAG -> 客户端追踪
```

而是：

```text
契约 -> 身份 -> 隔离 -> 联邦 -> 评测 -> 插件/产品
```

## 4. 子计划 A：P0/P1 契约

### A0 目标

```text
不动业务数据
只建立能容纳多格式、多库、多租户的骨架
```

### A1 决策清单

| 编号 | 决策 | 默认建议 |
|---|---|---|
| D1 | 物理隔离 | schema-per-library |
| D2 | catalog 位置 | 独立 schema |
| D3 | work 身份 | DOI/PMID/PMCID + 内容哈希兜底 |
| D4 | document 身份 | work + source_type + sha256 |
| D5 | 默认查询 scope | own |
| D6 | 去重策略 | 查询时 exact + 离线 near-duplicate |
| D7 | 主库权限 | 数据库角色只读 |
| D8 | MD 支持 | 第一版预留 source_type，不急着解析 |

### A2 DDL 任务

| 任务 | 内容 | 交付 |

| A2.2 | `works` | work_id / doi / pmid / title / year |
| A2.3 | `documents` | work_id / library_id / source_type / sha256 |
| A2.4 | `source_nodes` | 保持现有结构，加 library 兼容视图 |
| A2.5 | 约束 | unique(work_id, source_type, sha256) |
| A2.6 | 索引 | library_id, work_id, document_id |

### A3 兼容层

### A4 迁移工具

## 5. 子计划 B：P3 Bench smoke

### B0 目标

```text
用 20-30 篇公开全文 + 10 个问题
验证数据层能不能接住真实评测语料
```

### B1 语料

| 任务 | 内容 |
|---|---|
| B1.1 | 选 20-30 篇公开全文 |
| B1.2 | 记录 license |
| B1.3 | 保存原始文件 |
| B1.4 | 计算 sha256 |
| B1.5 | 固定 parser_version |

建议格式：

```text
PDF 10-15 篇
XML/JATS 10-15 篇
可选 MD 2-3 篇
```

### B2 解析

| 任务 | 内容 |
|---|---|
| B2.1 | 走生产解析管线 |
| B2.2 | 写 documents/source_nodes |
| B2.3 | 记录解析失败 |
| B2.4 | 不混入主库 |

### B3 金标

10 个问题，每个标：

```text
question
work_id
document_id
section_path
para_id
quote
page / char offsets
```

### B4 快照

```text
benchmark_snapshot
  corpus_hash
  parser_version
  gold_version
  created_at
```

### B5 运行

分两种：

```text
bench-only
main + bench federated
```

记录：

```text
document_parsed
node_alignment_ok
gold_mapped
retrieved
rank
```

### B6 验收

```text
>= 80% 文档解析成功
>= 90% 金标可映射
两次运行结果一致
```

### B7 失败处理

```text
解析失败 -> 记录，不硬删
对齐失败 -> 保留原始坐标
金标歧义 -> 进入仲裁清单
```

### B8 出口

```text
通过 -> 扩到 300 题
不通过 -> 修数据层，不扩题
```

## 6. 风险与调整

| 风险 | 影响 | 应对 |
|---|---|---|
| schema 改不动旧代码 | 阻塞 | 兼容视图，不直接替换 |
| 10k 回填出现孤儿 | 数据错误 | dry-run + 抽样 |
| 公开语料许可不清 | 不能入库 | 只选明确许可 |
| 解析器升级导致金标漂移 | 评测不可比 | 固定 snapshot |
| 联邦延迟过高 | 体验差 | 每库 top-k + 超时 |
| 租户 schema 太多 | 运维复杂 | 先 workspace 级，不做 user 级 |
| MD 解析器不成熟 | 延期 | 预留 source_type，不阻塞 |
