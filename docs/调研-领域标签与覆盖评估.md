# 领域标签与覆盖评估：开源方案调查报告

> **Status**: research report, no implementation decision  
> **Date**: 2026-11-01  
> **Question**: 3,310 篇论文缺少 domain_l1/l2 标签，是否有成熟开源项目/公开数据可直接复用？  
> **Related**: [Domain coverage audit](审计-领域覆盖.md), [Domain discussion](讨论-领域覆盖与领域感知路由.md)

---

## 1. 结论先行

```text
不推荐人工给 3,310 篇论文打领域标签。
优先用 OpenAlex Topics 自动映射；
生物医学部分用 Europe PMC / PubMed MeSH 校验；
Crossref subject 只做兜底；
BERTopic 只做探索性聚类，不做权威分类。
```

推荐顺序：

```text
1. OpenAlex Topics（全部论文，DOI 匹配）
2. Europe PMC / PubMed MeSH（生物医学子集校验）
3. Crossref subject（缺失兜底）
4. BERTopic（探索/发现新主题，不替代分类）
```

---

## 2. 当前数据 readiness

```text
papers                 3,310
with DOI               3,310  (100%)
with abstract          3,008  (90.9%)
with keywords          2,220  (67.1%)
domain labels              0
```

结论：

```text
DOI 全覆盖，非常适合做外部元数据 enrichment
不需要先人工标注才能开始
```

## 3. 候选方案对比

| 方案 | 粒度 | 覆盖 | 开放/许可 | 与 DOI 集成 | 适合度 |
|---|---|---|---|---|---|
| OpenAlex Topics | domain / field / subfield / topic | 全球学术作品 | 开放数据，CC0 | 原生 DOI | **首选** |
| Europe PMC MeSH | MeSH 主题词 | 生物医学 | 开放 API | DOI/PMCID | 生物医学校验 |
| PubMed E-utilities | MeSH | 生物医学 | 免费 API | PMID/DOI | 备选 |
| Crossref subject | 期刊/作品 subject | 不完整 | 开放 API | DOI | 兜底 |
| Semantic Scholar fieldsOfStudy | 粗粒度领域 | 广 | API key | DOI | 辅助 |
| arXiv categories | arXiv 分类 | 仅 arXiv | 开放 | arXiv ID | 不适用当前库 |
| BERTopic / Top2Vec | 无监督主题簇 | 本地 | 开源 | 文本 | 探索 |
| Scopus ASJC / WoS | 细分类 | 商业库 | 订阅 | 有限 | 不推荐 |

## 4. OpenAlex Topics（首选）

### 4.1 为什么适合

OpenAlex 的 work 对象包含：

```text
primary_topic
topics[]
```

每个 topic 带层级：

```text
domain
field
subfield
topic
```

并且有 `score`，可保留多标签而不是强行单标签。

参考：

- [OpenAlex Topics documentation](https://docs.openalex.org/api-entities/topics)
- [OpenAlex work object](https://docs.openalex.org/api-entities/works/work-object)
- [OpenAlex aboutness / topics](https://help.openalex.org/api/tag-aboutness/)
- [OpenAlex fields](https://help.openalex.org/data/fields/)

### 4.2 集成方式

按 DOI 取 work：

```text
GET https://api.openalex.org/works/https://doi.org/10.1001/jamadermatol.2026.3646
```

或批量过滤：

```text
GET https://api.openalex.org/works?filter=doi:10.1001/...,10.1002/...
```

Python 客户端：

- [pyalex](https://github.com/J535D165/pyalex)

### 4.3 建议落库字段

```text
paper_id
openalex_work_id
doi
primary_topic_id
primary_topic_name
domain_id / domain_name
field_id / field_name
subfield_id / subfield_name
topic_score
topics_json          # 多标签
label_source         # openalex
fetched_at
```

### 4.4 风险

```text
- topic assignment 是算法结果，不是人工 ground truth
- 多标签/跨领域论文可能被 primary_topic 简化
- 2026 年新论文可能尚未被 OpenAlex 收录
- 需要遵守 API 速率与 polite pool（mailto）
```

## 5. Europe PMC / PubMed MeSH（生物医学校验）

### 5.1 Europe PMC

Europe PMC REST 的 `resultType=core` 可返回：

```text
meshHeadingList
keywordList
```

参考：

- [Europe PMC REST API](https://europepmc.org/RestfulWebService)
- [Europe PMC Web Service Reference](https://www.ebi.ac.uk/europepmc/webservices/rest/)
- [Europe PMC Annotations](https://europepmc.org/Annotations)

适合当前 HCC / 肿瘤免疫语料，但不是全领域。

### 5.2 PubMed E-utilities

```text
esearch -> efetch -> MeSH headings
```

参考：

- [NCBI E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/)
- [MeSH homepage](https://www.nlm.nih.gov/mesh/meshhome.html)

### 5.3 建议

```text
OpenAlex 作为主标签
Europe PMC/PubMed MeSH 作为生物医学子集的交叉校验
```

不要只用 MeSH 覆盖全部 3,310 篇，因为非生物医学论文会缺标签。

---

## 6. Crossref subject（兜底）

Crossref work metadata 可能带 `subject` 字段，但：

```text
覆盖不完整
粒度不稳定
不同出版社差异大
```

参考：

- [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)
- [Crossref API works](https://api.crossref.org/works)

建议：

```text
只用于 OpenAlex 无结果的 DOI
不要把 Crossref subject 当主分类
```

---

## 7. Semantic Scholar（辅助）

Semantic Scholar 提供：

```text
fieldsOfStudy
s2FieldsOfStudy
```

粒度比 OpenAlex Topics 粗，适合做交叉验证。

参考：

- [Semantic Scholar Graph API](https://api.semanticscholar.org/api-docs/graph)

---

## 8. 无监督主题聚类（探索，不是分类）

### 8.1 BERTopic

- [BERTopic](https://github.com/MaartenGr/BERTopic)

适合：

```text
发现语料中未知主题
检查现有 taxonomy 是否漏掉小领域
可视化主题分布
```

不适合：

```text
直接替代权威领域标签
```

### 8.2 Top2Vec

- [Top2Vec](https://github.com/ddangelov/Top2Vec)

同样只建议做探索。

### 8.3 结论

```text
BERTopic/Top2Vec 可以作为 domain discovery
但不能作为 coverage audit 的唯一标签来源
```

- [RAGAS](https://github.com/explodinggradients/ragas)

用于：

```text

```

## 10. 建议的实施顺序

### Phase 0：导出 DOI

```text
3,310 个 DOI
归一化（小写、去 URL 前缀）
```

### Phase 1：OpenAlex enrichment

```text
按 DOI 批量取 primary_topic + topics
落 paper_domains 表或 CSV
```

### Phase 2：人工校验

```text
随机抽 100 篇
至少两人独立核对 domain/field
报告 agreement
```

### Phase 3：生物医学 MeSH 校验

```text
Europe PMC / PubMed 取 MeSH
与 OpenAlex 对比
```

### Phase 4：重跑覆盖审计

```text
papers_per_domain
papers_per_subfield
singleton_subfield_rate
query_domain
available_relevant_count
coverage_ceiling
```

### Phase 5：再决定 routing / penalty

```text
只有标签覆盖率和一致性达标后
才讨论 domain boost / topic penalty
```

## 11. 推荐的数据契约

```text
paper_domains
  paper_id
  source              openalex | europepmc | pubmed | crossref | manual
  domain_l1
  domain_l2
  domain_l3
  topic_id
  topic_name
  score
  is_primary
  fetched_at
```

约束：

```text
一篇论文允许多行（多标签）
primary_topic 只允许一行
label_source 必须可追溯
```

---

## 12. 不建议的做法

```text
人工给 3,310 篇全部打标签（成本高、不可复现）
用期刊名直接当领域
用 Crossref subject 当唯一分类
用 BERTopic 聚类结果当权威 taxonomy
用 lexical support 当 available_relevant_count
```

---

## 13. 最终建议

```text
首选 OpenAlex Topics
+ Europe PMC/PubMed MeSH 校验
+ Crossref 兜底
+ 100 篇人工抽样
```

如果 OpenAlex 对当前 3,310 篇 DOI 的覆盖率低于预期：

```text
再考虑 BERTopic + 人工 taxonomy
而不是先人工标注全部
```
