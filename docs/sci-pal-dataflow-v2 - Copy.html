1 数据下载层 — 从 NCBI/OpenAlex 获取原始文献
download_pmc_xml.py
PMC 全文 XML 下载器。通过 NCBI E-utilities (EFetch) 下载 JATS 格式 XML 全文。支持：自动过滤只有摘要无正文的文章（检查 <body> 标签）、断点续传、限速、批量下载。
NCBI EFetchJATS XML全文过滤
download_pubmed_abstracts.py
PubMed 摘要批量下载。通过 ESearch 搜 PMID → ESummary 批量取元数据 → EFetch 取摘要。输出 JSON 格式，含标题/作者/摘要/期刊/年份/DOI/PMID。
PubMed摘要JSON
download_openalex.py
OpenAlex 批量下载脚本。OpenAlex 是免费学术数据库，覆盖 2 亿+论文。支持按主题/作者/机构/期刊搜索下载元数据和摘要。
OpenAlex2亿+论文
batch_download_pmc.py
PMC 一键批量下载脚本。预置 5 大分类 42 个主题（免疫学/癌症/基因组学/分子生物学/顶刊 Cell/Nature/Science 等），每主题最多 100 篇，自动调用 download_pmc_xml.py。
批量42主题5大分类
fetch_from_ncbi.py
NCBI 数据获取工具封装。统一封装 ESearch/ESummary/EFetch/EPost 等 API，处理限速（有 API Key 10次/秒，无 Key 3次/秒）、重试、缓存。
E-utilities限速重试
fetch_metadata.py
论文元数据补全工具。根据 PMID/DOI/PMCID 从 NCBI 补全缺失的标题/作者/期刊/年份等元数据。
元数据补全
📄 PMC 全文 XML
documents_xml/*.xml
JATS 格式全文，含标题/摘要/正文/图表/参考文献
📝 PubMed 摘要 JSON
abstracts_xml/*.json
按主题分类的摘要数据，含元数据

2 数据导入层 — 解析 XML/JSON，写入 SQLite
import_xml_v2.py
【主力】JATS XML 解析导入器。解析 XML 提取：标题/作者/摘要/关键词/段落(含章节层级)/图表/参考文献。写入 papers 表和 paragraphs 表，parse_engine='xml'。支持增量导入（INSERT OR REPLACE）。
JATS解析段落切分增量导入
import_xml.py
【旧版】XML 导入器（v1），已被 import_xml_v2.py 替代，保留兼容。
旧版兼容
build_abstracts_db.py
摘要库构建器。读取 abstracts_xml/*.json，写入独立的 abstracts.db（FTS5 全文索引 + 向量索引）。使用 bge-base-en-v1.5 做 embedding。
摘要库FTS5向量索引
import_zotero_metadata.py
Zotero 元数据导入器。从 Zotero 导出的 CSV/JSON 导入论文元数据。
Zotero元数据
build_db/parsers/
PDF 解析器集合：parser_orchestrator（调度器）、docling_parser、grobid_parser、mineru_parser、pdfplumber_parser。支持多种 PDF 解析引擎，自动选择最优。
PDF解析多引擎
🗄️ 全文数据库
data/research.db
SQLite，含 papers/paragraphs/figures/tables/citations 等表
📚 摘要数据库
data/abstracts.db
SQLite，独立的摘要库，含 FTS5 全文索引

3 数据库构建层 — 建表/索引/图谱/社区
build_db/build_database.py
数据库初始化脚本。创建所有表结构：papers/paragraphs/figures/tables/citations/sentences/chunks/communities 等。定义索引和外键关系。
建表Schema
build_db/build_fts.py
FTS5 全文索引构建。为 paragraphs 表构建 SQLite FTS5 虚拟表，支持布尔搜索/短语搜索/前缀搜索。用于关键词精确匹配。
FTS5全文检索布尔搜索
build_db/build_paper_graph.py
论文引用图谱构建。解析参考文献，建立 CITES（引用）和 SIMILAR（相似）关系边。写入 paper_graph 表，用于图谱扩展检索。
引用图谱CITESSIMILAR
build_db/build_communities.py
论文社区发现。基于引用图谱使用 Louvain 算法进行社区检测，将论文聚类成主题社区。用于社区级检索和浏览。
Louvain社区检测聚类
build_db/build_chunks.py
文本分块器。将长段落切分成固定大小的 chunk（含重叠），用于更精细的向量检索。支持按句子/段落/固定字数分块。
分块Chunk重叠
build_db/build_sentences.py
句子级切分。将段落切分成句子，写入 sentences 表。用于句子级证据定位和引用校验。
句子切分证据定位
build_db/build_citation_index.py
引用索引构建。解析文内引用标记（如 [1]、(Smith et al., 2020)），建立句子-参考文献的对应关系。用于引用溯源。
引用索引文内引用
build_db/dedup_papers.py
论文去重工具。基于 DOI/PMID/标题相似度去重，避免重复论文入库。
去重DOI匹配

4 向量索引层 — Embedding + ChromaDB 向量库
build_paragraph_vector_index.py
【主力】段落级向量索引构建。读取 paragraphs 表，用 bge-base-en-v1.5 模型做 embedding，写入 ChromaDB（collection: sci_pal_paragraphs）。支持增量追加（collection.add）。
段落向量bge-baseChromaDB
build_vector_index.py
【旧版】向量索引构建（v1），已被 build_paragraph_vector_index.py 替代。
旧版
build_abstracts_db.py
摘要向量索引构建。为 abstracts.db 构建独立的 ChromaDB 向量库（data/chroma_abstracts/），用于摘要库语义检索。
摘要向量独立库
services/search/reranker.py
Cross-Encoder 重排序器。使用 bge-reranker-base 模型对向量+FTS 召回的候选结果进行精排。输入 query+段落，输出相关性分数，提升检索精度。
RerankCross-Encoderbge-reranker
Embedding 模型: BAAI/bge-base-en-v1.5 (768维) Rerank 模型: BAAI/bge-reranker-base 向量库: ChromaDB (HNSW 索引, 余弦相似度) 批量 embedding (batch_size=256) 增量追加 (collection.add, 不重建)
🔢 全文向量库
data/chroma/
ChromaDB，collection: sci_pal_paragraphs，HNSW 索引
🔢 摘要向量库
data/chroma_abstracts/
ChromaDB，独立的摘要向量库

5 检索与生成层 — 混合检索 + 综述生成 + QA

5.1 检索模块 (services/search/)

unified_retriever.py
【核心】统一检索器。串联完整检索流水线：查询路由 → 混合搜索(向量+FTS) → Rerank重排 → MMR去重 → 上下文扩展(small-to-big) → 图谱扩展 → 摘要库检索。输出结构化 evidence envelope。
统一检索流水线Envelope
hybrid_search.py
混合搜索核心。向量检索(ChromaDB) + FTS5全文检索，用 RRF (Reciprocal Rank Fusion) 算法融合两路结果。支持多查询扩展(Multi-Query)、动态权重、MMR多样性选择。
向量+FTSRRF融合Multi-Query
query_router.py
查询路由器。根据查询类型（事实型/方法型/综述型/比较型）选择不同的检索策略和权重。用 scispacy NER 提取关键实体做实体增强检索。
查询路由NER实体策略选择
context_expander.py
上下文扩展器。Small-to-Big 策略：检索命中精确段落(chunk)后，扩展到其父章节(section)，提供更完整的上下文。用 ►◄ 标记命中位置。
Small-to-Big上下文扩展
graph_traverser.py
图谱遍历器。基于论文引用图谱(CITES/SIMILAR)，从命中论文出发扩展查找相关论文，补充向量检索可能遗漏的关联文献。
图谱扩展CITESSIMILAR
mmr_diversifier.py
MMR 多样性选择器。Maximal Marginal Relevance 算法，在相关性和多样性之间平衡，避免返回的段落内容重复。
MMR多样性
abstract_search.py
摘要库检索器。独立检索 abstracts.db（FTS5 + 向量），作为全文检索的补充。当全文库结果不足时，从摘要库补充候选论文。
摘要检索补充检索
online_search.py
【V33.1】在线搜索模块。封装 NCBI E-utilities，同时搜 PubMed+PMC。ESearch搜ID → ESummary批量取元数据。内置限速、本地缓存、3次重试。
在线搜索NCBIPubMed/PMC
hybrid_retriever.py
【V33.1】混合检索器。并行搜索本地+在线，三级去重(PMCID→PMID→DOI)，统一排序。本地论文标 source=local，在线新论文标 source=online。
本地+在线三级去重并行搜索
online_downloader.py
【V33.2】在线下载器。异步下载PMC XML → 增量导入DB → 增量建索引。三阶段进度跟踪(下载40%+导入30%+索引30%)。任务队列管理，同时只跑1个任务。
异步下载增量导入任务队列

5.2 综述生成模块 (services/review/)

review_generator.py
【核心】综述生成主流程。串联：主题→检索→证据抽取→大纲生成→分章节撰写→引用校验→Markdown输出。V32.5新增：分章节生成+渐进式上下文注入+章节类型感知+证据-声明矩阵+迭代精炼评审。
综述生成分章节证据约束
evidence_extractor.py
证据抽取器。用 LLM 从检索到的段落中抽取结构化证据卡片(EvidenceCard)，含：证据类型/章节/关键发现/实验方法/样本量/结论。简化证据抽取模式(不调LLM，直接用段落做证据卡片)。
证据抽取EvidenceCardLLM
outline_generator.py
大纲生成器。根据证据卡片自动生成综述大纲(章节/段落)，或接受用户自定义大纲。支持大纲模板(系统综述型/叙事型/方法学型)。每章节有关键词用于按大纲搜索文献。
大纲生成模板自定义
citation_verifier.py
引用校验器。确定性校验：检查每个引用标记是否存在、引用的证据是否支撑该句子。可选 LLM 深度校验：判断引用是否恰当、是否有断章取义。
引用校验确定性LLM深度
llm_client.py
LLM 客户端。支持 Ollama (qwen2.5:3b/7b) 和云端 OpenAI 兼容 API。统一接口，自动重试，流式输出。
LLMOllamaOpenAI兼容
relation_extractor.py
关系抽取器（问答/分析功能用）。抽取论文间的实验条件对比、方法对比、结论冲突等关系。V31.82 综述生成已跳过此步骤。
关系抽取问答用
conflict_detector.py
冲突检测器（问答/分析功能用）。检测不同论文间的结论矛盾、方法差异。V31.82 综述生成已跳过。
冲突检测问答用

5.3 QA 模块 (services/qa/)

qa_service.py
RAG 学术问答服务。基于统一检索器获取证据，用 LLM 生成带引用的回答。支持多轮对话、证据溯源、关系抽取、冲突检测。
RAG问答多轮对话证据溯源

6 API 与前端层 — Flask API + 多页面前端

6.1 API 层

api_server.py
【核心】Flask API 服务器。统一入口，端口5000。提供：检索API(/api/retrieve)、综述API(/api/review/*)、问答API、论文API、混合搜索API(/api/search/hybrid、/api/search/online)、下载API(/api/search/download_online、/api/search/download_status)、历史/队列/重试API。
FlaskREST API统一入口
routes/
路由模块：ai_routes.py(AI相关)、paper_routes.py(论文管理)、search_routes.py(搜索)、writing_routes.py(写作)。按功能模块化路由。
路由模块化

6.2 前端页面 (frontend/)

index.html
【主页】搜索页。单文件应用(HTML+CSS+JS)。功能：关键词搜索、混合检索(本地+在线NCBI/PMC)、结果展示(段落/图表/表格/论文/图谱关联)、在线文献勾选下载、下载进度展示、下载历史面板、配置面板、Toast通知。
搜索主页混合检索下载管理
review.html
综述生成页。三栏布局：大纲编辑器(左) + 相关论文列表(中) + PDF阅读器(右)。功能：大纲模板选择/编辑、按大纲搜索并分配论文、生成综述、引用溯源点击定位PDF。
综述生成三栏布局大纲编辑
qa.html
RAG 问答页。多轮对话界面，回答带引用标记，可点击溯源到原文段落。支持关系对比、冲突检测。
RAG问答多轮对话
compare.html
双栏对比页。左右两篇论文并排展示，支持同步滚动、差异高亮。用于论文对比阅读。
双栏对比
viewer.html
PDF 阅读器页。独立 PDF 阅读器，支持批注、高亮、目录导航。
PDF阅读器
