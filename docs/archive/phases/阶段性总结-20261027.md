## 二、工作流

### 1. API 与路由
- 内联路由 43 → 2，拆成 15 个蓝图；
- 解析入口统一到 `build_db/parse_service.py`；
- 修复拆分遗留的 `NameError`、`_find_parsed_paper` 未定义、标注 500→404。

### 2. PDF 三引擎
- Docling 正文 + 质量门 + MinerU 兜底 + GROBID 元数据/引用；
- 字段级 provenance（`parse_provenance`）；
- GROBID CRF/Full 双端点切换；MinerU 4.x 适配；
- 服务启动脚本 + 开机自启。

### 3. 结构化 v2
- `sections` 显式父子；段落绑定 `section_id`；
- `sentences` 带 page/bbox/section_id/char offsets；
- `citation_mentions` + `sentence_links`（来源/置信度）；
- `paper_links` 统一文章关系；
- 结构审计脚本 `audit_structure`（0 悬挂引用）；
- 清理 37,873 条孤儿句子、155,413 条句子回填 section_id。

### 4. 文献源
- JATS 导入器（`<sec>` 树、refs/figures/tables、xref 句级链接 1.0）；
- Europe PMC 游标批量（1,015 篇；后遇服务 503 停止）；
- 预印本（arXiv/bioRxiv/medRxiv）PDF 入库；
- 元数据回填（Crossref → OpenAlex）；
- XML 图表回退链接（jats-regex 0.6）。

### 5. 图表提及与溯源
- `mention_patterns`：Fig/Figure/Figs 多编号、范围、Table/Tables、中文 图/表；
- 排除 supplementary / extended data / supporting information；
- caption 校正 `fig_number`（211 条冲突）；
- 句子溯源 API：`/api/papers/<id>/trace` + `trace.png`，前端 `frontend/trace.html`。

### 6. 文章图谱
- Crossref references、OpenAlex referenced_works、OpenAlex cited_by；
- `paper_links` 164,802 条（cites / cited_by / similar）。

## 三、已知限制

1. XML 论文无 bbox（格式决定）；MinerU 兜底路径无 bbox；
2. 未被正文提及的图表、未被引用的参考文献没有位置（本身不存在）；
3. 旧 PDF 的 GROBID 回填覆盖 42 篇（5,400 mentions / 3,192 链接），仍有个别 PDF 没有正文引用标记；
4. Europe PMC 搜索服务 503 时无法继续扩量；
5. PDF 章节树来自 Docling 标题推断，XML 才是原生结构；
6. `paper_links` 外部 DOI 边多于本地互引。

## 四、下一步

- 用 trace API 做引用高亮前端；
- OpenAlex cited_by 扩到全部有 DOI 的论文；
- 给 `sentence_links` 增加外键约束，把审计接入启动自检。
