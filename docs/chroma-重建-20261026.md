## 踩的坑：重建脚本只建了 paragraphs

`rebuild_chroma.py` 只重建 `paragraphs`，但线上索引还有 `papers` / `figures` / `tables` 三个集合。切换后表现：

```
/api/search/hybrid  → total=0（本地检索静默为空）
原因：search_papers 里 self.paper_collection 为 None → AttributeError 被吞
```

## 修复

1. 新增 `scripts/restore_side_collections.py`：从 `research.db` 重建三个集合
   （papers 2,076 / figures 219 / tables 114，约 1 分钟）；
2. `HybridSearch.search_papers` 增加兜底：没有 `papers` 集合时，用段落命中
   聚合出论文级结果，不再静默返回空；
3. 回归测试 `tests/test_search_papers_fallback.py`。
