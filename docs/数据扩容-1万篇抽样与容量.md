

```text

```

如果按滚动 5 年，则用：

```text

```

---

## 3. 格式分层

每年 2,000 篇：

| 层 | 数量/年 | 说明 |
|---|---:|---|
| XML 全文 | 1,200 | PMC/Europe PMC JATS |
| PDF-only | 600 | 无 XML，走 PDF 解析 |
| 摘要-only | 200 | 仅 metadata + abstract |

合计：

```text
XML 全文   6,000
PDF-only   3,000
摘要-only  1,000
```

说明：

```text
“格式均匀”不可能严格成立
PMC 全文以 XML 为主，PDF 覆盖不均
用配额保证每层都有，而不是强行 1:1
```

---

## 4. 主题分层

建议至少覆盖：

```text
肿瘤
心血管
神经
感染/免疫
代谢/内分泌
方法/工具
公共卫生
其他
```

每年每主题：

```text
≥ 100 篇
```

避免 10,000 篇集中在单一领域。

---

## 5. 纳入 / 排除

纳入：

```text
2021-11 至 2026-10
英文
有 PMID 或 PMCID
OA 许可允许全文/摘要使用
研究论文 / 综述
元数据完整
```

排除：

```text
重复 DOI/PMCID/标题
撤稿
无法解析
纯图片/幻灯片
非英文
```

如果“PPT”指幻灯片，需要单独数据源；PMC 不提供 PPT。

---

## 6. 抽样方法

```text
1. 从 Europe PMC / PMC OA 拉候选池
2. 按年份 + 格式 + 主题分层
3. 每层随机抽样，固定 seed
4. 预留 2 倍替换池
5. 解析失败按替换池补
```

产出清单字段：

```text
pmid
pmcid
doi
title
year
month
format
topic
license
source_url
```

## 7. 容量清单

按当前 3,315 篇线性外推 10,000 篇：

| 项目 | 当前 | 10k 估算 |
|---|---:|---:|
| papers | 3,315 | 10,000 |
| paragraphs | 167,388 | ~505,000 |
| sentences | 862,677 | ~2,600,000 |
| embeddings | 166,470 | ~502,000 |
| PG | 3.19 GB | ~9.6 GB |
| Chroma | 4.1 GB | ~12.4 GB |
| HNSW 索引 | 0.64 GB | ~1.9 GB（含在 PG） |

原始文件：

```text
XML 6,000 × 0.2 MB  ≈ 1.2 GB
PDF 3,000 × 4 MB    ≈ 12 GB
摘要 1,000          ≈ 0.1 GB
```

工作空间：

```text
下载临时     10–20 GB
解析缓存      5–10 GB
备份快照     10–15 GB
```

总需求：

```text
PG + Chroma + 原始 + 临时 + 备份
≈ 60–75 GB
```

建议磁盘：

```text
当前剩余 20 GB
至少再加 200 GB
保留 30% 空闲
```

## 8. 时间估算

不要直接外推 10,000 篇。

先跑：


测：

```text

HNSW 构建时间

```

再按 500 篇实测外推 10,000 篇。


```text

```

```text

```

```text

```

## 10. 验收门槛

```text
1. 10,000 篇入库，失败率 < 5%
2. PG/Chroma 均能重建
3. 300 题评测完成
4. pgvector 非劣于 Chroma

```

不满足：

```text
不进入 10 万篇阶段
```

---

## 11. 风险

```text
OA 覆盖随年份下降
PDF 许可不一致
API 限流
解析失败集中在某些出版商
重复/撤稿
存储增长快于预期
```

缓解：

```text
分层配额 + 替换池
先 500 篇试产
记录每层失败率
保留原始清单与哈希
```

---

## 12. 结论

```text
1 万篇可行
但当前磁盘不够
当前语料不是 5 年均匀
必须先扩盘 + 500 篇试产
```
