# 架构变更授权：P4c2 剩余业务写迁移

> 日期：2026-11-08  
> 状态：**待人类批准修改**  
> 规则：`.dsh_rules` 规则 0A  
> 前置：P4c 默认 tenant 连接

---

## 1. 问题

默认连接已是 tenant_writer，但以下仍由 owner 写 public：

```text
systematic review
references
protocols
tenancy（身份面）
review tasks
```

盘点：

```text
review_projects          1
screening_decisions      1
adjudications            0
evidence_rows            1
risk_of_bias             0
review_webhooks          0
reference_library        1
protocol_imports         1
```

这些表没有 workspace_id（`review_projects` 只有 owner）。

---

## 2. 变更

改哪一层：

```text
schema + 写入路径
```

新增归属字段：

```text
review_projects.workspace_id
review_tasks.workspace_id
reference_library.workspace_id
protocol_imports.workspace_id
protocol_runs.workspace_id
protocol_attachments.workspace_id
```

回填：

```text
ws_default
```

迁入租户：

```text
lib_ws_default.review_projects
review_project_papers
screening_decisions
adjudications
evidence_rows
risk_of_bias
review_webhooks
review_tasks
reference_library
protocol_imports
protocol_runs
protocol_attachments
```

代码切换：

```text
services/review/pg_systematic.py
services/review/pg_tasks.py
services/references/library.py
services/protocols/pg_runs.py
services/protocols/pg_attachments.py
```

从 owner 改回默认 tenant + search_path。

---

## 3. 理由

```text
systematic/references/protocols 是用户业务
应进租户
tenancy 是身份面
必须留在 public owner
```

例外：

```text
users / workspaces / memberships / tenancy_audit
```

这些不迁，否则登录和工作区解析会循环依赖。

