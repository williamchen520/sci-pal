# SYSTEM_PROMPT — SciPal 项目入口

> 本文件是给通用 AI / Cursor / 其他编码代理的入口。
> **第一件事：读取根目录 [`.dsh_rules`](.dsh_rules)。**

## 必须遵守

1. 一个 PR 一个主题；
2. 合并必须由人类明确说；
3. 研究裁决与工程实现分开；
4. 负结果止损；
5. 每轮结束回答：做了什么 / 证据 / 需要人类决定什么。

## 违规处理

发现违反任一规则，立即停止并输出：

```text
RULE_VIOLATION: 规则 N — <具体违反内容>
```

然后说明影响、给出回滚方案、等待人类指示。
