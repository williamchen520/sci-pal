# P6：应用数据库最小权限

> 日期：2026-11-11  
> 状态：**已切换到最小权限角色；admin 账号退出应用 DSN**

---

## 1. 角色

```text
scipal_core_app
  scipal_core
  auth / public / lib_ws_default
  SELECT / INSERT / UPDATE / DELETE
  USAGE / SELECT sequences
  无 DDL

scipal_corpus_reader
  scipal_rebuild
  SELECT only

scipal_corpus_writer
  scipal_rebuild
  SELECT / INSERT / UPDATE / DELETE
  无 DDL
```

## 2. DSN 映射

```text
SCIPAL_CORE_DSN            -> scipal_core_app
SCIPAL_AUTH_DSN            -> scipal_core_app
SCIPAL_PG_DSN              -> scipal_core_app
SCIPAL_PG_TENANT_WRITE_DSN -> scipal_core_app

SCIPAL_PG_MAIN_READ_DSN    -> scipal_corpus_reader
SCIPAL_PG_CORPUS_DSN       -> scipal_corpus_reader

SCIPAL_PG_OWNER_DSN        -> scipal_corpus_writer
SCIPAL_PG_INGEST_DSN       -> scipal_corpus_writer
```

`scipal_admin` 不再出现在应用运行 DSN 中。

## 3. 验证

```text
smoke A 27/27 200
smoke B 13/13 200
```

应用只读/写业务与语料，不能：

```text
DROP TABLE
ALTER TABLE
CREATE ROLE
```

备份容器使用同一组只读/业务角色；如 pg_dump 需要额外权限，应单独创建 backup 角色，不得回退 admin。

## 4. 风险

```text
密码仍存在 deploy/.env
未接入 secret manager
角色密码轮换需同步 app + pg-backup
```
