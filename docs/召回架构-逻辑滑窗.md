# 召回架构：智能逻辑滑窗

> 日期：2026-11-10  
> 状态：prototype，未接生产路由

---

## 1. 目标

```text
命中句子负责定位
逻辑滑窗负责恢复原意
扩展句不参与任何排序
```

## 2. 四条规则

### 逻辑词优先

命中句向上下扫描；遇到配置的逻辑词无条件拉入。

### 废话熔断

无逻辑词且 Query 相关性低于阈值 -> 跳过。

### 物理边界

section_id 变化、标题句、空行 -> 停止该方向扫描。

### 硬性字数

最终 `text` 不超过 `max_chars`（默认 1200）。

## 3. 配置

```text
config/context_policy.json
  max_chars
  max_scan
  relevance_threshold
  logic_terms（en/zh，可扩展）
  heading_terms
```

环境覆盖：

```text
SCIPAL_CONTEXT_POLICY
SCIPAL_CONTEXT_MAX_CHARS
SCIPAL_CONTEXT_LOGIC_TERMS
```
