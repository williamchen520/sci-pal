## 3. 检索与证据数据流

```mermaid
%%{init: {"flowchart": {"curve": "basis"}}}%%
sequenceDiagram

  participant API as Flask /api/retrieve

  participant RR as Reranker

  participant LLM as DSH 模型

  U->>API: query
  API->>HS: search()
  HS->>CH: 向量召回 paragraphs
  HS->>FTS: BM25 召回
  HS->>HS: RRF 融合 + MMR
  HS->>RR: cross-encoder 重排
  RR-->>HS: top-k 段落
  HS->>CE: 小→大扩展
  CE->>DB: para → section 路径 + 邻段 + 句子
  DB-->>CE: 上下文 + bbox + links
  CE-->>API: 证据信封
  API-->>U: 证据包（JSON/Markdown）
  U->>LLM: 生成
  LLM->>API: verify_answer
  API-->>LLM: ok / warnings
```

## 6. 存储结构

```
research.db
├─ papers                 元数据、parse_engine、acquisition
├─ sections               显式父子（parent_id），path/depth
├─ paragraphs             section_id/sequence/page/bbox
├─ sentences              para_id/sequence/page/bbox/char offsets
├─ citations              参考文献
├─ figures / tables       图表
├─ citation_mentions      正文引用位置（GROBID）
├─ sentence_links         句子 ↔ 引用/图/表（source/confidence）
├─ paper_links            文章图谱（cites/cited_by/similar）
├─ tasks / ingest_tasks   任务
└─ FTS: papers_fts, paragraphs_fts
```

Chroma：`paragraphs`（全文本）、`papers`、`figures`、`tables`。
