# 评测说明

> 配套代码：`eval/`、`tests/test_eval.py`
> 目的：让检索/生成改动有可量化的回归依据。

## 1. 金标准（E1）

- 文件：`eval/gold/seed_100.jsonl`（30 curated + 70 auto）；
- 100 题，覆盖：
  - factual 10；
  - comparison/qualifier 8；
  - methods 4；
  - refusal 4；
  - multi-hop 4。
- 每题带真实 `paper_id` 与 `sentence_id`，已校验存在；
- `answer_points` 用短要点，不写整段答案。

## 2. 检索评测（E2）

```powershell
python eval/retrieval_eval.py --limit 10
```

计算：

- Recall@k：命中证据句比例；
- MRR：首个命中排名；
- nDCG@k：二值相关性；
- 拒答：gold 无证据时，返回空证据即正确。

首次 5 题基线：

```
recall@10 = 0.60
mrr       = 0.35
ndcg@10   = 0.41
```

## 3. 生成评测（E3）

```powershell
python eval/answer_eval.py --answers eval/answers/sample.jsonl
```

计算：

- 要点覆盖率（token 重合 ≥50%）；
- 禁用断言命中；
- 平均引用数；
- 拒答正确率。

## 3.1 拒答信号

`to_evidence_json` 返回 `sufficient` 与 `sufficiency`：

```json
{"sufficient": false, "top_score": 0.99, "query_coverage": 0.33}
```

阈值：

- `SCIPAL_SUFFICIENCY_MIN_SCORE=0.2`
- `SCIPAL_SUFFICIENCY_MIN_COVERAGE=0.5`

## 4. 接 CI

后续在 GitHub Actions 增加：

```yaml
- run: python -m unittest discover -s tests -p "test_*.py"
- run: python eval/retrieval_eval.py --limit 20 --output eval/results/ci.json
- run: python eval/answer_eval.py --answers eval/answers/ci.jsonl
```

门禁：`recall@10` / `ndcg@10` 下降 >2% 失败。

已提供：

- `eval/gate.py`：比较 baseline/current，失败退出 1；
- `.github/workflows/eval.yml`：self-hosted runner（需本机 Flask + 依赖）。

## 5. 注意

- 评测依赖运行中的 Flask（`:5000`）；
- 30 题只覆盖少量主题，后续按月扩充；
- 金标准涉及版权，只存 ID 与短要点，不存全文；
- `eval/results/*.json` 可提交作为基线。
