# 工作计划：领域自适应对齐

> 目标：让通用基座在不同领域部署时，自动对齐语料、查询与回答策略，而不是固定成 HCC/ICI 产品。  
> 范围：P0 先做“语料画像 + 软路由 + 领域化拒答”，P1/P2 再做用户画像与在线自适应。

## 1. 背景

当前矛盾：

- 语料：泛生物医学 3,308 篇；
- 评测：HCC/ICI 100 题，只来自 30 篇论文；
- 回答：通用 prompt，answer-level refusal 为 0。

表现：

- 检索被跨领域噪声稀释；
- 引用多但 coverage 低；
- 证据不足时仍强行作答。

根因不是树结构或 embedding，而是：

```
语料范围、评测范围、回答策略三者不匹配
```

## 2. 设计原则

1. **通用基座 + 领域适配层**
2. **软对齐，不硬过滤**
3. **领域多标签，不互斥**
4. **用户画像可解释、可关闭**
5. **先有分领域评测，再做自适应**

## 3. 三层结构

### 3.1 通用基座
- 检索、证据契约、引用、拒答框架；
- 不预设学科子领域；
- 可移植到其他部署。

### 3.2 领域自适应层
- 语料画像：论文领域弱标签；
- 查询路由：query → 领域分布；
- 领域策略：证据标准、拒答阈值、回答模板、术语表。

### 3.3 用户自适应层
- 搜索关键词习惯；
- 常用领域；
- 证据偏好；
- 显式反馈。

## 4. 数据模型

```sql
domain_profiles(
  domain_id, name, description,
  keywords, centroid,
  evidence_schema, refusal_threshold,
  created_at
)

paper_domains(
  paper_id, domain_id, confidence, source
)

query_logs(
  id, query, domain_distribution,
  selected_paper_ids, feedback, created_at
)

user_profiles(
  user_id, domain_weights, keyword_weights,
  preferences, updated_at
)
```

现有 `papers/sections/paragraphs/sentences` 不改，只加旁表。

## 5. P0：语料画像 + 软路由 + 领域化拒答

### 5.1 语料画像
- 标题/摘要/关键词；
- 期刊；
- 章节类型；
- embedding 聚类；
- 弱标签 + 置信度。

冷启动：

- 无标签 → `general`；
- 管理员可命名；
- 允许手工修正。

### 5.2 查询路由

```
query embedding + keywords + user history
→ domain distribution top-k
```

规则：

- 高置信度：本领域优先；
- 低置信度：允许跨领域；
- 综述/宏观：多领域并集；
- 用户显式指定：覆盖自动判断。

### 5.3 检索软先验

```
score += λ * domain_similarity
```

不直接 `WHERE domain = X`，避免过滤掉跨领域证据。

### 5.4 领域化拒答

```
通用拒答契约
+ 领域证据标准
+ 用户偏好
```

领域策略示例：

- 肿瘤：ORR / PFS / OS / HR；
- 其他领域：各自核心终点；
- 证据不足 → 强制拒答分支。

### 5.5 分领域评测

至少两套 gold：

1. HCC/ICI（现有）；
2. 另一个领域（如阿尔茨海默/内分泌）。

指标：

- 领域路由准确率；
- in-domain answer coverage；
- cross-domain leakage；
- refusal precision/recall；
- 冷启动 vs 老用户。

## 6. P1：用户画像

- 查询日志；
- 显式反馈（点赞/点踩/切换领域）；
- 隐式信号低权重；
- 用户可查看/重置；
- 3–5 次交互后启用个性化。

## 7. P2：在线自适应

- 反馈更新；
- 时间衰减；
- 防漂移；
- 分领域回归评测；
- 灰度开关。

## 8. 风险

- 反馈偏差；
- 领域标签不足；
- 用户隐私；
- 过滤气泡；
- 跨领域证据被误伤；
- 小样本过拟合。

回滚：

- 所有自适应开关默认关闭；
- 可退回通用模式；
- 领域路由可人工覆盖。

## 9. 验收

P0：

- 领域路由 top-1 准确率 ≥ 0.8（人工抽样）；
- HCC in-domain coverage 不下降；
- 新增领域 coverage 有提升；
- answer-level refusal 从 0 提升到 ≥ 0.5；
- 延迟增加 ≤20%。

## 10. 里程碑

1. 领域画像 + 标签缓存；
2. 查询路由 + 软先验；
3. 领域化 prompt/拒答；
4. 第二领域 gold；
5. A/B 与结果文档。

## 11. 非目标

- 不做全量在线学习；
- 不硬编码 HCC；
- 不牺牲通用基座；
- 不在没有分领域评测前宣称自适应有效。
