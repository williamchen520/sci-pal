# 句子角色选句实验

> 状态：实验完成，不默认启用。

## 方法

`services/search/sentence_roles.py`：

- 句子分类：result / method / limitation / background / other；
- 结果句特征：数字、百分比、p 值、HR/OR/RR、response/survival 等；
- 按 query intent 给角色加权；
- 替换 `ContextExpander._pick_highlight` 的纯词重合。

## 开关

```powershell
$env:SCIPAL_ANCHOR_ROLES = "1"
```

默认关闭。

## 30 题结果

| 指标 | baseline | 角色选句 |
|---|---|---|
| sentence strict@10 | 0.5192 | 0.5192 |
| paragraph@10 | 0.7692 | 0.7885 |
| sentence-in-paragraphs | 0.8462 | 0.8462 |
| refusal | 0.75 | 0.75 |
| top20 strict | 0.6538 | 0.6154 |

## 结论

- top10 strict 没有提升；
- top20 反而下降；
- 说明 gold 句子不总是“结果句”，规则角色分类覆盖不足；
- 保留为实验开关，不默认启用。

## 下一步

- 或直接做 answer-level eval，判断角色选句对回答质量的影响。
