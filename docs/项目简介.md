## 2. 标准简介（约 300 字，适合 README 开头 / 项目主页）

SciPal 是一个本地优先的科研文献检索与写作辅助系统。它把论文解析成「章节—段落—句子—图表—引用」结构树，结合向量检索、FTS5/BM25、Cross-Encoder 重排与结构化上下文，返回可定位到页码和 bbox 的证据包；在此基础上支持 RAG 问答、综述生成、文献监测（Watch）与 DSH/MCP 工具化调用。

系统支持 JATS XML 与 PDF（Docling / GROBID / MinerU 三引擎）入库，可对接 Europe PMC、PubMed、arXiv、bioRxiv、Crossref、OpenAlex、Unpaywall；生成层可接本地 Ollama 或云端大模型，并通过 `verify_answer` 做引用与冲突校验。数据侧提供本地数据沙箱：原始 Excel/CSV/TSV/DOCX 不出本地，只向云端提供 n≥10 的聚合统计与脱敏样例，并记录审计。

适合需要「结果可复核、数据可控」的实验室与个人研究者。

## 3. 完整简介（约 600 字，适合项目介绍页 / 申请材料）

SciPal 面向科研文献的检索、理解与写作，核心目标不是“让模型写得更多”，而是“让每个结论都能回到原文”。

它首先解决结构问题：JATS XML 原生解析，PDF 走 Docling + GROBID + MinerU 三引擎，产出章节树、段落、句子、图表、参考文献与句级引用位置。检索层把向量召回、BM25、RRF 融合、Cross-Encoder 重排和小→大上下文扩展组合起来，返回的不是零散句子，而是「命中句 + 所在段落 + 前后段 + 完整章节路径 + page/bbox + 引用/图表链接」的证据包。

在证据包之上，SciPal 提供：

- RAG 问答与综述生成，生成后强制 `verify_answer`，引用缺失或冲突未说明限定条件时只算草稿；
- 文献监测（Watch）：按领域、期刊、指标定期发现新文献，OA 全文优先，非 OA 存摘要，生成简报；
- 科研数据沙箱：原始表格/文档只在本地处理，云端只接收聚合统计与脱敏样例，聚合阈值 n≥10，全链路审计；
- DSH/MCP 集成：检索、证据、校验、监测、数据工具都可被 Agent 调用，也可独立 HTTP 使用。

部署上支持单机或 GPU 服务器，生成层可切换本地 Ollama 与云端模型；模型串行加载，适配 8GB 显存。项目采用 AGPL-3.0-only。
