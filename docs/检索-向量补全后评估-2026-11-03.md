## 3. Gate 结果

```text
eval/gate.py
ok=false
failures: recall@10 0.5729 < 0.65 - 0.02
```

但这次 gate 比较本身不严谨：

```text
baseline: 20 题
current:  96 题
```

`eval/gate.py` 只比较 summary，不校验题目集合是否一致，属于**样本不可比**。

所以：

```text
gate 失败可以作为告警
不能直接判定为 20 题回归
```

## 4. 解释

向量补全改变了候选池：

```text
paragraphs   +18,560 有效向量
papers        +1,237
sections      +7,196
figures      +12,879
tables        +4,805
```

候选池变大后：

```text
更多段落进入 hybrid recall
rerank/MMR 排序会变化
旧 20 题的排名可能下降
```

这不等同于“向量修复是错的”，但说明：

```text
现有 20 题基线已不适合作为唯一 gate
需要固定 gold 集合和固定样本再比较
```

## 5. 建议

```text
1. 固定 q001–q020 作为回归集
2. 固定 full 96/100 作为趋势集
3. gate 必须校验 gold id 集合
4. 先看同 gold 的 paired 指标，不看 summary 对 summary
```

## 6. 结论

```text
向量覆盖修复完成
全量 96 题 recall 0.5729
同 20 题对齐 recall 0.575，低于旧 0.65
需要一次固定样本复核，再决定是否调 hybrid/rerank
```
