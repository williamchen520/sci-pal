# 引用意图（citation intent）

> 目标：区分“支持 / 反驳 / 仅提及”，为冲突检测和综述写作提供依据。
> 当前是规则版，零模型成本；后续可换小模型分类器。

## 1. 表

`sentence_links` 新增：

```sql
intent TEXT  -- support | contrast | mention
```

索引：

```sql
idx_sentence_links_intent ON sentence_links(target_type, intent)
```

## 2. 分类规则

`services/search/citation_intent.py`：

- contrast：however / in contrast / unlike / whereas / contradict / failed to…
- support：consistent with / in line with / support / confirm / corroborate…
- 其余：mention

优先级：contrast > support > mention。

## 3. 回填

```powershell
python -m build_db.citation_intent_schema
```

已回填：

```
mention  195,809
contrast  30,490
support   22,689
```

## 4. 使用

- 证据包 `links[].intent` 已带出；
- 后续在冲突检测中优先看 `contrast`；
- 综述/问答可提示“该引用为反驳/支持”。

## 5. 限制

- 规则只覆盖显式转折/支持词，隐式反讽/否定会漏；
- 同一句引用多篇时共用一个 intent；
- 需要人工抽检 precision，后续用 3B 模型做二分类。
