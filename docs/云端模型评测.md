# 云端模型评测

> 定位：本地小模型只做调度，答案生成 / claim 校验 / 拒答裁决交给云端或 DSH 模型。

## 1. 分工

### 本地
- query 归一化；
- 意图分类；
- 领域判断；
- 检索计划；
- 预算/路由。

### 云端
- 答案生成；
- 跨文献综合；
- claim 级校验；
- 拒答裁决；
- LLM judge。

## 2. 配置

DeepSeek / OpenAI 兼容：

```powershell
$env:SCIPAL_LLM_PROVIDER = "openai"
$env:SCIPAL_LLM_BASE_URL = "https://api.deepseek.com/v1"
$env:SCIPAL_LLM_API_KEY = "sk-..."
$env:SCIPAL_LLM_MODEL = "deepseek-chat"
$env:SCIPAL_LLM_LIGHT_MODEL = "deepseek-chat"
```

DSH 模型若提供 OpenAI 兼容端点，同样配置。

检查：

```powershell
python scripts\check_llm_provider.py
```

## 3. 重跑顺序

1. 10 题 answer-level smoke test；
2. 30 题拒答题专项；
3. 100 题主评测；
4. 与本地 7B 对比：
   - coverage；
   - refusal；
   - citations；
   - latency；
   - token 成本。

## 4. 需要重跑的结论

- answer coverage；
- answer-level refusal；
- grounding 阈值；
- 领域化拒答；
- LLM judge。

检索层结论仍有效：

- contextual adaptive；
- sentence seeds；
- TreeRouter / AutoMerging 无效。

## 5. 安全

- API key 只放环境变量，不写库；
- 不把未公开论文发送到外部 provider；
- 需要时提供本地 provider 或私有网关；
- 记录 token 与成本。
