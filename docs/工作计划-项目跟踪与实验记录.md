# 工作计划：项目跟踪与实验记录（ELN）

> 状态：待评审  
> 范围：第 2 项（项目、设计、protocol.io、实验记录、Run、审计、电子签名、权限）  
> 定位：完整 ELN，先达到“带审计的 ELN”，不宣称法规认证。

## 1. 决策与假设

| 项 | 决策 |
|---|---|
| 目标 | 完整 ELN |
| 合规 | 先按机构科研诚信（B），不宣称 21 CFR Part 11 |
| 电子签名 | 需要 |
| protocol.io | 快照 + 手动刷新 |
| Experiment / Run | 保留两级 |
| Protocol | 实验必须挂 protocol 版本 |
| 成员互看 | 不能 |


如果未来要做法规合规：

- 单独做验证计划；
- SOP；
- 培训；
- 保留策略；

## 4. Project

字段：

- 标题、摘要；
- PI；
- 成员与角色；
- 状态：planning / active / paused / completed / archived；
- 开始/结束日期；
- 里程碑；
- workspace；
- 数据分级；
- 关联文献；
- 关联简报。

规则：

- 项目属于一个 workspace；
- 不支持跨 workspace；
- 归档后只读；
- PI 可见项目元数据与成员，不可见成员实验内容（除非获批）。

- 版本化；
- 可关联多个 protocol；
- 可导出；

## 6. Protocol

### 来源

- protocols.io 快照；
- 本地手写 protocol；
- 未来可接其他仓库。

### 快照

```text
protocol_id
source: protocols_io | local
external_id
doi
url
version
license
snapshot_path
fetched_at
```

- 固定版本；
- 手动刷新；
- 保留旧版本；
- 不自动同步；
- 许可随快照。

### 实验绑定

Experiment 必须指定：

```
protocol_id
protocol_version
```

不允许“无 protocol 的正式实验”。

探索性实验也必须使用本地 protocol（可为空模板）。

- 设计引用；
- 操作者；
- 开始/结束；
- 状态；

### Run

## 8. 修订、审计、签名

### Revision

- 追加式；
- 不覆盖历史；
- 每条 revision 有 hash；
- 当前指针指向最新。

### Audit

记录：

- 谁；
- 何时；
- 哪个字段；
- 旧值/新值；
- 原因；
- 关联 signature。

### E-signature

```text
signer
meaning: author | reviewer | approver
timestamp
record_hash
re_auth_method
```

规则：

- 签名前重新认证；
- 签名绑定 revision hash；
- 签名后锁定；
- 修改必须新建 revision；
- 审计记录原因。

不宣称法律效力，只做研究记录完整性。

## 9. 权限

### 默认

- 实验记录 private；
- 成员不能互看；
- PI 不能直接看；
- 管理员不能看内容；
- 项目元数据对成员可见。

### PI 请求流程

```
PI request
→ member approve/deny
→ time-bound read-only
→ audit
→ expire/revoke
```

- PI 不能强制；
- 成员可拒绝；
- 批准范围：单个 experiment 或时间窗；
- 默认不允许导出；
- 成员可看请求记录。

### 项目结题

不自动开放；仍按请求流程。

## 10. 原始数据 DataRef

只存引用：

```yaml
path:
host:
protocol: local | smb | nfs
checksum:
size:
data_class:
access_note:
```

规则：

- 不复制进 ELN；
- DSH 只读调用；
- 路径白名单；
- 拒绝 `..`；
- 记录访问审计；
- 路径失效标记。

### 重要限制

应用层权限不能替代 OS 权限。

如果 PI 获批但无 OS 权限，仍读不到文件；  
如果 PI 有 OS 权限，ELN 无法阻止直接读取。

因此需要：

- OS ACL；
- 共享组；
- 或数据服务代理。

计划书必须写明这个边界。

领域包提供：

```text

├─ design.yaml
├─ experiment.yaml
├─ run.yaml
└─ deviations.yaml
```

示例：

- 湿实验；
- 动物实验；
- 临床试验；
- 干实验/计算；
- 材料/化学。

## 13. 与文献/简报

- 项目关联文献；
- 实验可引用文献；
- 简报条目可加入项目；
- 设计可引用证据；
- 不自动把 private 实验发送到云端。

## 14. AI 辅助

允许：

- 总结实验记录；
- 对比 design vs actual；
- 提取偏差；
- 生成 protocol 草稿；
- 关联文献。

限制：

- private 只用本地/超算；
- 生成内容标记 draft；
- 不自动签名；
- 不自动改动记录。

```sql
  revision_id, experiment_id, revision,

  run_id, experiment_id, title, status,

  deviation_id, run_id, field, planned, actual,

  signature_id, revision_id, signer,

  request_id, experiment_id, requester,

  id, workspace_id, actor, action,
  object_type, object_id, old_value, new_value,
  reason, created_at

```

## 16. 迁移现有

现有：

- `protocol_imports`
- `protocol_steps`
- `experiment_runs`
- `experiment_run_files`

迁移：

1. 创建默认项目；
2. run 绑定 project/experiment；
3. 旧 protocol 变为快照；
4. 旧文件变 DataRef 或附件；
5. 默认 private；
6. 保留原 ID；
7. 可回滚。

## 18. 验收

- 实验必须挂 protocol；
- 计划/实际偏差可记录；
- 签名后锁定；
- 修订不可覆盖；
- 审计完整；
- 成员互不可见；
- PI 必须请求；
- private 不出网；
- DataRef 可解析；
- 旧 run 可迁移；
- 导出含审计。

## 19. 风险

- 合规过度承诺；
- 电子签名法律效力；
- OS ACL 与 ELN 权限不一致；
- 路径失效；
- 协议许可；
- 项目归档策略；
- 审计数据增长；
- 成员协作不足。
