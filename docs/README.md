## 为什么不立即 git mv

```text
438 篇文档，348 篇在 docs/ 根目录
现有 43 个本地链接已经断开
全量移动会新增断链，并让 RAG 语料出现重复/重定向
```

所以先建立分类索引、时间轴和稳定入口；物理迁移等链接检查器就绪后再做。
