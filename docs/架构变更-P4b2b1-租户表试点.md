## 1. 问题

P4b2a 只加了归属字段，数据仍在 `public`。

证据：

```text
reviews       29 行，workspace_id=ws_default
notes          0 行，workspace_id=ws_default
lib_ws_default 空 schema
tenant_writer  未接应用
```

后果：

```text
tenant schema 只是存在
租户写入没有真实落点
主库仍承载全部业务数据
```

---

## 2. 变更

改哪一层：

```text
schema + 写入路径（试点）
```

P4b2b1 只试点两张低风险表：

```text
reviews
notes
```

新增：

```text
lib_ws_default.reviews
lib_ws_default.notes
```

方式：

```text
CREATE TABLE ... (LIKE public.reviews INCLUDING ALL)
复制 workspace_id='ws_default' 的行
```

应用切换：

```text
SCIPAL_TENANT_PILOT=reviews,notes
```

代码：

```text
ReviewRepository
Notes service
按开关写/读 lib_ws_default
public 保留原行，作为回滚副本
```

不做：

```text
不搬 projects / experiments / claims / tasks / watch
不改 public 表
不切 tenant_writer 到所有写路径
```

---

## 3. 理由

```text
reviews/notes 无子表依赖
行数小
失败可回滚到 public
```

先验证：

```text
租户 schema 可写
应用可切换
权限不破坏
回滚可控
```

再扩到有子表的 projects/experiments/claims。

---

## 4. 影响

数据：

```text
reviews 29 行复制
notes 0 行复制
```

代码：

```text
review_repository
notes service
```

兼容性：

```text
默认开关关闭
关闭时仍用 public
```

风险：

```text
双份数据不一致
切换后 public 变旧
```

缓解：

```text
先只读对比
再写租户
public 保留
```

---

## 5. 迁移

步骤：

```text
1. 建 lib_ws_default.reviews/notes
2. 复制 ws_default 行
3. 加开关
4. 单端点验证
5. 打开写租户
6. 对比计数
```

回滚：

```sql
DROP TABLE IF EXISTS lib_ws_default.reviews;
DROP TABLE IF EXISTS lib_ws_default.notes;
```

关闭开关即回 public。
