✅ 引用校验器
services/review/citation_verifier.py
两层校验：①确定性校验(检查引用标记是否存在、引用ID是否有效、引用的证据是否存在) ②可选LLM深度校验(判断引用是否恰当、是否断章取义、是否过度引用)。
校验方法：确定性校验(存在性/有效性) + LLM深度校验(恰当性/断章取义检测)
确定性校验 LLM深度校验

🔎 第4层：检索引擎层 (Retrieval Engine)
向量检索 · FTS5 · RRF融合 · Rerank · MMR · 图谱扩展
🎯 统一检索器
services/search/unified_retriever.py
检索流水线总指挥。串联：查询路由→混合搜索→Rerank重排→MMR去重→上下文扩展(small-to-big)→图谱扩展→摘要库补充。输出结构化 evidence envelope(段落+图表+表格+论文+图谱关联)。
流水线：QueryRouter → HybridSearch → Reranker → MMR → ContextExpander → GraphTraverser → AbstractSearch
流水线 Envelope
⚡ 混合搜索
services/search/hybrid_search.py
向量检索(ChromaDB, bge-base embedding) + FTS5全文检索(SQLite) 双路召回。用 RRF (Reciprocal Rank Fusion, k=60) 算法融合两路结果。支持多查询扩展(Multi-Query, 生成2-4个查询变体)、动态RRF权重、MMR多样性选择。
算法：向量检索(余弦相似度) + FTS5(BM25) + RRF融合(k=60) + Multi-Query扩展 + MMR去重
向量检索 FTS5 RRF融合 Multi-Query
🔄 Rerank 重排序
services/search/reranker.py
Cross-Encoder 精排。用 bge-reranker-base 模型对候选(query, paragraph)对打分。输入查询+段落文本，输出0-1相关性分数。将向量+FTS粗排的前50-100条精排到前10-20条，大幅提升精度。
模型：BAAI/bge-reranker-base (Cross-Encoder) · 输入(query, passage) → 输出相关性分数
Cross-Encoder bge-reranker 精排
🧭 查询路由器
services/search/query_router.py
查询分类与策略选择。用 scispacy NER 提取关键实体(基因/蛋白/疾病/药物)，做实体增强检索。根据查询类型(事实型/方法型/综述型/比较型)选择不同检索权重和策略。
方法：scispacy NER实体提取 · 查询分类 · 实体增强检索 · 策略选择
NER scispacy 实体增强
📏 MMR 多样性选择
services/search/mmr_diversifier.py
Maximal Marginal Relevance 算法。在相关性(与query相似度)和多样性(与已选段落的差异)之间平衡，避免返回内容重复的段落。公式：MMR = λ*Sim(q,d) - (1-λ)*max Sim(d,d_selected)。
算法：MMR (Maximal Marginal Relevance) · λ平衡相关性与多样性
MMR 多样性
🌐 上下文扩展
services/search/context_expander.py
Small-to-Big 策略。检索命中精确段落(chunk)后，扩展到其父章节(section)，提供更完整的上下文。用 ►◄ 标记原始命中位置，方便LLM定位关键信息。
策略：Small-to-Big · chunk → section 扩展 · 命中位置标记
Small-to-Big 上下文扩展
🕸️ 图谱遍历器
services/search/graph_traverser.py
基于论文引用图谱扩展。从命中论文出发，沿 CITES(引用) 和 SIMILAR(相似) 边扩展查找相关论文，补充向量检索可能遗漏的关联文献。最多扩展2跳。
方法：图谱遍历 · CITES/SIMILAR 边 · 2跳扩展
图谱扩展 CITES SIMILAR
📚 摘要库检索
services/search/abstract_search.py
独立摘要库检索。检索 abstracts.db(FTS5+向量)，作为全文检索的补充。当全文库结果不足或需要更多候选论文时，从摘要库补充。
方法：摘要库 FTS5 + 向量检索 · 补充检索
摘要库 补充检索
🌐 在线搜索 (V33.1)
services/search/online_search.py
NCBI 在线搜索。封装 E-utilities：ESearch搜ID → ESummary批量取元数据。同时搜 PubMed+PMC。内置限速(有Key 10次/秒，无Key 3次/秒)、本地缓存(24小时)、3次重试。
方法：NCBI E-utilities · ESearch+ESummary · 限速 · 缓存 · 重试
NCBI PubMed PMC
🔀 混合检索器 (V33.1)
services/search/hybrid_retriever.py
本地+在线并行搜索。ThreadPoolExecutor 并行执行。三级去重：PMCID → PMID → DOI，任一匹配即重复，优先保留本地版本。统一排序(按score降序)。自动检查在线论文是否已在本地。
方法：并行搜索 · 三级去重(PMCID/PMID/DOI) · 本地优先 · 统一排序
并行 三级去重 本地优先
⬇️ 在线下载器 (V33.2)
services/search/online_downloader.py
异步下载+增量导入+增量建索引。三阶段：①下载PMC XML(自动过滤只有摘要的) ②增量导入DB(INSERT OR REPLACE，不清空) ③增量建索引(只对新论文embedding，collection.add追加)。任务队列管理(同时只跑1个)，进度跟踪(下载40%+导入30%+索引30%)，持久化到JSON。
方法：异步线程 · 增量导入 · 增量索引 · 任务队列 · 进度跟踪 · 持久化
增量 异步 队列

🔢 向量数据库
ChromaDB (data/chroma/)
全文段落向量库。collection: sci_pal_paragraphs。HNSW 索引，余弦相似度。存储：ids(para_id) + documents(段落文本) + embeddings(768维向量) + metadatas(paper_id, section_l1)。支持增量追加(collection.add)。
索引：HNSW (Hierarchical Navigable Small World) · 余弦相似度 · 768维向量
ChromaDB HNSW 768维
📝 摘要向量库
ChromaDB (data/chroma_abstracts/)
独立的摘要向量库。用于摘要库语义检索，与全文库分离。同样使用 bge-base-en-v1.5 做 embedding。
ChromaDB 独立库
🔍 FTS5 全文索引
SQLite FTS5 (research.db)
SQLite 内置全文搜索引擎。为 paragraphs 表建 FTS5 虚拟表。支持：布尔搜索(AND/OR/NOT)、短语搜索("...")、前缀搜索(word*)、NEAR操作。BM25 排序算法。用于关键词精确匹配，与向量检索互补。
算法：FTS5 · BM25排序 · 布尔搜索 · 短语搜索 · 前缀搜索 · NEAR操作
FTS5 BM25 布尔搜索
🧠 Embedding 模型
BAAI/bge-base-en-v1.5
文本向量化模型。768维输出，英文优化。用于段落和摘要的 embedding。本地路径：D:\models\models\BAAI--bge-base-en-v1.5。批量编码(batch_size=256)。
模型：BAAI/bge-base-en-v1.5 · 768维 · 英文优化 · 批量编码
bge-base 768维 本地加载
🎯 Rerank 模型
BAAI/bge-reranker-base
Cross-Encoder 重排序模型。输入(query, passage)对，输出0-1相关性分数。比双编码器(Bi-Encoder)精度高，但速度慢，用于精排阶段。本地路径：D:\models\models\BAAI--bge-reranker-base。config.json 需手动加 model_type=bert。
模型：BAAI/bge-reranker-base · Cross-Encoder · (query, passage) → score
bge-reranker Cross-Encoder 精排

🌍 第7层：数据源层 (Data Sources)
NCBI E-utilities · PubMed · PMC · OpenAlex · 本地PDF
📚 NCBI PubMed
生物医学文献摘要数据库。3500万+文献。通过 E-utilities API 访问：ESearch(搜ID) → ESummary(取元数据) → EFetch(取摘要)。有 API Key 限速 10次/秒，无 Key 3次/秒。
PubMed E-utilities 3500万+
📄 NCBI PMC
开放获取全文数据库。1000万+全文。JATS XML 格式。通过 EFetch 下载全文 XML。支持 open access[filter] 过滤。自动过滤只有摘要无正文的文章(检查<body>标签)。
PMC 全文XML 1000万+
🌐 OpenAlex
免费学术数据库。2亿+论文。覆盖所有学科。REST API，无需 API Key。支持按主题/作者/机构/期刊搜索。用于补充 NCBI 未覆盖的文献。
OpenAlex 2亿+ 免费
📁 本地 PDF
用户本地 PDF 文件。支持多种解析引擎：docling/grobid/mineru/pdfplumber。parser_orchestrator 自动选择最优引擎。解析后写入 research.db。
PDF 多引擎解析
📦 Zotero/EndNote
文献管理软件导出的元数据。支持 CSV/JSON 格式导入。用于补全论文元数据。
Zotero EndNote
