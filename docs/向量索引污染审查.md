# 向量索引污染审查

> 日期：2026-11-07

## 1. 结论

在建立向量索引前，原先**没有段落级审查**。

`build_embeddings_pg.py` 只过滤：

```text
text IS NOT NULL
length(btrim(text)) >= 10
```

因此编号、作者名、单位、图表标签、参考文献片段都可能进入向量索引。

## 3. 新增过滤器

```text
services/ingest_quality/paragraph_filter.py
```

规则：

```text
空文本
参考文献/致谢/关键词章节
纯编号/图表标签
URL/DOI
作者/单位片段
纯数字
无字母
全大写标题
编号标题
标题式短句
```

接入：

```text
build_embeddings_pg.py
```

后续新入库段落先过滤，再编码。
