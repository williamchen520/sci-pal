## 0. 决策

```text
scipal_core
  auth.*       users / roles / permissions / user_configs
               workspaces / memberships / tenancy_audit
  public.*     projects / experiments / notes / tasks / claims
```


## 1. 现状审计

当前只有：

```text
users
workspaces
memberships（role 是 text：owner/pi/member/viewer）
```

不存在：

```text
roles
permissions
user_configs
```

也没有跨这些表的物理外键。

所以“打破 FOREIGN KEY”在鉴权层基本已经是事实；需要做的是：

```text
把 text role 升级为 roles/permissions
把 users/workspaces/memberships 迁入 auth schema
确保 corpus 不出现这些表
```

## 3. 角色与权限映射

```text
owner   -> all 7 permissions
pi      -> read_workspace / write_own / read_all / copy
member  -> read_workspace / write_own
viewer  -> read_workspace
```

迁移 SQL：

```sql
INSERT INTO auth.users (user_id, username, email, display_name,
                        password_hash, status, is_admin, created_at)
SELECT user_id, username, email, display_name,
       password_hash, status, is_admin, created_at
FROM public.users;

INSERT INTO auth.workspaces (workspace_id, name, owner_user_id, created_at)
SELECT workspace_id, name, owner_user_id, created_at
FROM public.workspaces;

INSERT INTO auth.memberships (workspace_id, user_id, role_id, status, created_at)
SELECT workspace_id, user_id, role, status, created_at
FROM public.memberships;

INSERT INTO auth.user_roles (user_id, role_id, workspace_id)
SELECT DISTINCT user_id, role, workspace_id
FROM public.memberships;

INSERT INTO auth.tenancy_audit (workspace_id, actor_user_id, action, target, detail, created_at)
SELECT workspace_id, actor_user_id, action, target, detail, created_at
FROM public.tenancy_audit;
```

`user_configs` 初始为空：

```sql
-- 按需写入，不迁移
```

`is_admin` 保留；不要把它复制成 owner，admin 是全局权限，owner 是 workspace 角色。

## 4. 连接层

新增：

```python
auth_connection()
```

优先级：

```text
SCIPAL_AUTH_DSN
  -> SCIPAL_CORE_DSN
  -> SCIPAL_PG_DSN
```

生产 DSN 建议：

```text
SCIPAL_AUTH_DSN=postgresql://.../scipal_core?options=-csearch_path%3Dauth%2Cpublic
SCIPAL_CORE_DSN=postgresql://.../scipal_core
SCIPAL_PG_CORPUS_DSN=postgresql://.../scipal_rebuild
```

如果独立 auth 库：

```text
SCIPAL_AUTH_DSN=postgresql://.../scipal_auth
SCIPAL_CORE_DSN=postgresql://.../scipal_core
```

代码改动点：

```text
services/db/pg_pool.py
  auth_connection()

services/tenancy/pg_service.py
  _admin() -> auth_connection()
  authorize() -> 查 role_permissions

services/tenancy/pg_writes.py
  _connect() -> auth_connection()
  不再用 admin_connection 写 users/workspaces/memberships

services/tenancy/permissions.py
  audit() -> auth.tenancy_audit
```

`auth_connection` 只服务鉴权；项目/实验/笔记用 `core_connection`。

## 7. 跨库逻辑关联

```text
papers.owner_user_id   -> auth.users.user_id
projects.owner_user_id -> auth.users.user_id
notes.user_id          -> auth.users.user_id
```

应用层组装：

```text
1. auth 查用户/权限
2. corpus 查文献
3. MCP 合并结果
```

禁止：

```text
SQL JOIN auth.users 和 papers
跨库外键
跨库事务
```

用户删除：

```text
auth.users.status = 'disabled'
不级联删除 papers/projects
```

## 8. 风险

```text
1. search_path 未设置 -> 查到 public 旧表
2. 双写窗口 -> memberships 分叉
3. role_id 映射漏值 -> 登录后无权限
4. 跨库无 FK -> 孤儿 owner_user_id
5. 事务边界 -> 创建用户/工作区需 saga 或补偿
```

每个风险都有检查：

```text

```
