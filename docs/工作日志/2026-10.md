**遇到的问题与解决**：

1. **问题：装 bundle 前手写 patch 残留会 serverName 重名加载报错**
   - 现象：`~/.dsh/profiles/desktop/cordis.patch.yml` 里还残留清场前的手写 `mcp-scipal` / `mcp-scipalhello` 的 `- insert:` 块（108 行 / 6 条）。

2. **问题：旧 DSH 进程残留，把旧 MCP 配置挂成"活跃工具"，造成误判**
   - 现象：18:22 清场后，18:26 DSH 仍报"6 个 mcp__ 工具活跃"，但当时 `python.exe` 子进程 0 个 —— 模型凭旧日志/recovery 快照编清单。
   - 解决：建立"进程时间线法"判据——比 patch 文件 mtime 与 `DeepSeek Harness.exe` 的 CreationDate；清场后必须**完全退出重启再问一次**，否则会把"残留"误判成"bundle 已生效"。写入 INSTALL.md 步骤 0.7（重启验伪）。

3. **问题：误以为"开 Full access 后 plugin_manager 就能用"（初版 INSTALL.md 写错了）**
   - 现象：最初步骤 0.5 写成"开 Full access 后 `plugin_manager` 暴露"。实测 `permissions.preset = danger-full-access`（Full access 确实开了），但 `plugin_manager` / `cordis_inspect_list` / `cordis_inspect_query` **三个全部 `unknown tool`**。

4. **问题：原计划用 `cordis_inspect_query` 做免授权验证，本机也不存在**
