## 4. 为什么 paragraph precision 只有 0.10

回答通常引用 8–11 个段落，而 gold evidence 只对应 1 个段落：

```
precision = 命中 gold 的引用段落 / 全部引用段落
```

所以 0.10 不代表引用错误，而是“答案覆盖了多个上下文，gold 只标了一个点”。  
更有意义的指标是：

```
gold_hit：至少一个引用段落覆盖 gold
sentence_recall：gold 句子被引用句覆盖
```
