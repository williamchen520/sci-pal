# 架构变更授权：P4 最终切换

> 日期：2026-11-08  
> 状态：**待人类批准修改**  
> 规则：`.dsh_rules` 规则 0A  
> 前置：P4a / P4b1 / P4b2a / P4b2b1-3 完成

---

## 1. 问题

所有租户表已复制，但开关仍关闭。

当前：

```text
SCIPAL_TENANT_PILOT   未设置
app                   写 public
watch-cron            写 public
租户表                有历史副本，但不再增长
```

后果：

```text
租户隔离只停留在“副本 + 可用代码”
没有真实运行
public 仍是唯一写目标
```

---

## 2. 变更

改哪一层：

```text
运行配置 + 写入路径
```

设置：

```text
SCIPAL_TENANT_PILOT=reviews,notes,projects,experiments,claims,tasks,watch
```

影响容器：

```text
app
watch-cron
```

操作：

```text
1. 停 app + watch-cron
2. 快照 public / lib_ws_default 相关表
3. 设置开关
4. 启动 app + watch-cron
5. 验证
```

不修改：

```text
代码
public 表结构
租户表结构
```

---

## 3. 理由

```text
app 与 watch-cron 共用 .env
必须同一批切换，避免分叉
```

切换后：

```text
reviews/notes        -> tenant
projects/experiments -> tenant
claims               -> tenant
tasks/watch          -> tenant
papers/ingest        -> public（不变）
```

---

## 4. 影响

写入目标：

```text
public 相关表停止增长
lib_ws_default 相关表开始增长
```

风险：

```text
切换后回滚，public 不包含新增租户数据
watch-cron 与 app 不同步会分叉
```

缓解：

```text
切换前 pg_dump 快照
切换时 app/cron 同时停
先做单端点写入验证
观察 24h 再收缩 public 权限
```

---

## 5. 迁移

切换前：

```bash
pg_dump --data-only --table=... > public_before_p4.sql
pg_dump --data-only --schema=lib_ws_default > tenant_before_p4.sql
```

切换：

```text
停止 app / watch-cron
设置 SCIPAL_TENANT_PILOT
启动 app / watch-cron
```

回滚：

```text
停止 app / watch-cron
恢复 public 快照
删除 SCIPAL_TENANT_PILOT
启动 app / watch-cron
```

注意：

```text
回滚会丢弃切换后写入租户的数据
必须先确认没有必须保留的新数据
```
