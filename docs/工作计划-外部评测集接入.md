# 工作计划：外部评测集接入

> 目标：用高质量公开评测集替代现有 auto 题，作为主评测；保留内部人工回归集。  
> 原则：数据隔离、许可合规、按数据集分别报告。

## 1. 背景

现有 100 题中 69 题是 auto 生成：

- answer_points 常为关键词/作者名；
- 问题畸形或截断；
- coverage 0.686，严重拉低整体；
- 不适合作为模型/检索/结构选择依据。

需要外部高质量题集。

## 2. 候选与定位

| 数据集 | 规模 | 任务 | 定位 |
|---|---|---|---|
| **LitQA2** | 199 题 | 生物医学文献 QA | 主评测 |
| **SciFact** | 1,409 claims | claim 验证 | 引用/证据专项 |
| **QASPER** | 5,049 题 | 论文抽取式 QA | 可移植性验证（可选） |
| **ScholarQA** | 数千题 | 综述 + 引用 | 后续 |
| PubMedQA | 1,000 题 | yes/no/maybe | 不作为主评测 |

参考：

- [LitQA2 / PaperQA2](https://github.com/Future-House/paper-qa)
- [SciFact](https://github.com/allenai/scifact)
- [QASPER](https://huggingface.co/datasets/allenai/qasper)
- [OpenScholar / ScholarQA](https://aclanthology.org/anthology-files/anthology-files/pdf/acl/2025.acl-demo.49.pdf)

> 下载前必须确认每个数据集的 license 与再分发条款；不把原始数据提交进仓库。

- `papers`

## 4. 统一评测 schema

```json
{
  "id": "litqa2_001",
  "source": "litqa2",
  "question": "...",
  "paper_ids": ["..."],
  "evidence": ["sentence_id..."],
  "answer_points": ["..."],
  "category": "external",
  "difficulty": "unknown"
}
```

要求：

- `paper_ids` 必须是 benchmark 库内 ID；
- `evidence` 必须是 benchmark 库 sentence IDs；
- `answer_points` 是可验证短句/数值，不是关键词；
- `source` 用于分组报告。

## 5. LitQA2 接入

### 步骤

1. 下载 LitQA2 数据；
2. 读取题目、gold answer、关联文献标识（DOI/PMCID/标题）；
3. 只导入评测需要的论文；
4. 用现有解析/导入流程建 `papers/sections/paragraphs/sentences`；
5. 把题目映射到本地 `paper_id`；
6. 用 gold evidence 定位 sentence ID；
7. 生成统一 schema；
8. 先跑 20 题 smoke test。

### 难点

- 论文可能不在本地库；
- PDF 获取依赖网络；
- DOI/标题匹配可能失败；
- gold answer 是短答，`answer_points` 需要转换。

### 处理

- 匹配失败 → 标记 `unmapped`，不进入主评测；
- 先做 20 题，确认可行再扩到 199。

## 6. SciFact 接入

### 定位

不是开放式 QA，而是：

```
claim + evidence abstract → support / refute
```

适合评估：

- 引用是否支持结论；
- 证据句定位；
- 拒答/不确定判断。

### 步骤

1. 下载 claims + abstracts；
2. 把 abstract 作为短文档入库；
3. 每句切分并建 sentence ID；
4. claim 作为 `question`；
5. gold evidence sentence 作为 `evidence`；
6. label（SUPPORT/REFUTE）作为 `answer_points` 的约束。

## 7. QASPER（可选）

- 1,585 篇 NLP 论文、5,049 题；
- 质量高，但领域不匹配；
- 只用于验证“换领域后结构是否可用”；
- 不建议作为主评测。

- sentence-in-returned-paragraphs。

### 答案

- citation gold_hit；
- sentence_recall；
- refusal_accuracy。

## 12.1 P0 调研结果（2026-10-29）

### LitQA2
- 已从 LAB-Bench 获取 `litqa-v2-public.jsonl`（199 题）；
- 每题含 `question` / `ideal` / `distractors` / `sources` / `key-passage`；
- 与本地 `papers.doi` 匹配：**0 / 199**；
- 直接接入不可行，需要先把 199 篇源论文导入独立 benchmark 库；
- 多数 DOI 为 Nature/Cell/eLife 等，PDF 获取与许可需逐篇确认。

### SciFact
- 已下载官方数据（约 3.1 MB）；
- `corpus.jsonl` 5,183 篇摘要；
- `claims_train/dev` 含 claim、evidence sentence、SUPPORT/CONTRADICT；
- 不依赖 PDF，接入成本低；
- 任务是 claim 验证，不是开放式 QA。

### LitQA2 20 题 smoke

| 阶段 | 数量 |
|---|---|
| 题目 | 20 |
| Europe PMC 全文获取 | 13 |
| key-passage 定位 | 8 |
| 可评测 | 8 |

结果（仅 8 题）：

```
doc_recall@10 = 1.00
sentence_recall@10 = 1.00
```

样本过小，不作为主评测；需要提高全文获取率与 key-passage 匹配。

### 决策调整
- **P0 先做 SciFact 20 claims smoke**：
  - 摘要级 benchmark 库；
  - 评估检索 + 证据定位 + 引用支持；
- LitQA2 推迟到论文导入方案确定后；
- 本地内部回归集继续保留。

## 13. 建议

先做：

```
LitQA2 20 题 smoke
+ SciFact abstract 子集
```

两者都验证后，再扩 LitQA2 199。
