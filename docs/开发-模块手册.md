## 2. 模块详情

### 2.1 Core / System

```text
routes/core.py
routes/system.py
services/search/unified_retriever.py
```

职责：

```text
GET /api/health
POST /api/retrieve
GET /api/graph/stats
GET /api/communities
```

改这里通常影响全局；先确认 `SCIPAL_PG_DSN` 和检索开关。

### 2.2 Papers

```text
routes/papers.py
routes/papers_actions.py
services/papers/pg_writes.py
services/papers/preflight.py
build_db/parse_service.py
build_db/db_writer.py
```

职责：

```text
GET  /api/papers
GET  /api/papers/<paper_id>
GET  /api/papers/<paper_id>/graph
GET  /api/papers/<paper_id>/trace
GET  /api/papers/<paper_id>/trace.png
GET  /api/papers/local
GET  /api/papers/<paper_id>/supplementary
```

写路径：

```text
upload / parse
  -> parse_service
  -> DatabaseWriter
  -> preflight
  -> PostgreSQL
```

注意：

```text
PG-only 下 DatabaseWriter 不再读 SQLite schema
filename 通过 _paper_filename 查 PG
```

### 2.3 Search

```text

  pg_vector.py
  pg_fts.py
  pg_paragraph_retriever.py
  summary_search.py
  reranker.py
  context_expander.py
  ingest.py
```

职责：

```text
POST /api/search/hybrid
POST /api/search/online
POST /api/search/download_online

```

```text

  + PG FTS recall

  -> bge-reranker
```

关键规则：

```text

```

`summary_search`、`evidence` 也必须过滤重复。

## 3. 通用开发规则

### 3.1 新增路由

```text
routes/<name>.py
  -> build_<name>_blueprint()
  -> api_server.py 注册
```

### 3.2 新增 PG 读路径

```text
1. 加开关，默认保持旧路径
2. PG 分支先返回
3. 异常不静默回退 SQLite
4. 加 smoke 测试
```

### 3.3 禁止事项

```text
不要在 PG-only 路径里 sqlite3.connect
不要在请求路径里 ensure_schema
不要用 SQLite 作为回退
不要让 Chroma 成为必需依赖
```

### 3.4 测试

```text
tests/                        单元/集成
scripts/smoke_http.py         A 组 31 条
scripts/smoke_group_b.py      B 组 14 条
scripts/smoke_group_c.py      C 组 5 条
```

验收：

```text
0 个 5xx
research.db absent
```
