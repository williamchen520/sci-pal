# 架构变更：数据层物理隔离（scipal_core / scipal_rebuild）

> 日期：2026-11-11  
> 状态：**脚本与连接层已准备；生产尚未执行 DDL**  
> 规则：`.dsh_rules` 规则 0A

---

## 1. 问题

当前是 split-brain：

```text
检索 -> scipal_rebuild（13,201 篇）
业务 -> scipal_bench（3,301 篇 + users/projects）
```

继续把业务表往文献库合并，会让：

```text
业务备份被 41 万段落/34 万向量拖慢
文献重建影响登录/项目
权限边界模糊
```

## 2. 变更

```text
scipal_core
  users / workspaces / memberships / tenancy_audit
  projects / experiments / notes / tasks
  claims / review / watch / protocol
  无 papers / paragraphs / sentences / embeddings

scipal_rebuild
  papers / paragraphs / sentences / sections
  paragraph_embeddings / citations / figures / tables
  无 users / projects / experiments / notes
```

跨库只做逻辑关联：

```text
papers.owner_user_id  ->  users.user_id   （不建 FK）
notes.paper_id        ->  papers.paper_id （不建 FK）
```

## 3. 影响

```text
业务连接：SCIPAL_CORE_DSN
文献连接：SCIPAL_PG_CORPUS_DSN
身份/任务：core_connection()
检索：corpus_connection()
```

业务库可独立高频备份；文献库可低频备份/重建。

## 4. 迁移

### 建业务库

```bash
SCIPAL_CORE_DSN=.../scipal_core \
SCIPAL_PG_ADMIN_DSN=.../scipal_bench \
python scripts/init_core_db.py
```

### 建文献库（灾备/重建）

```bash
psql "$SCIPAL_PG_CORPUS_DSN" -v ON_ERROR_STOP=1 \
  -f deploy/sql/scipal_corpus_schema.sql
```

### 校验边界

```bash
SCIPAL_CORE_DSN=.../scipal_core \
SCIPAL_PG_CORPUS_DSN=.../scipal_rebuild \
python scripts/check_data_boundary.py
```

期望：

```text
DATA_BOUNDARY_OK
```

## 5. 回滚

```text
业务 DSN 指回旧库
删除 SCIPAL_CORE_DSN
重启 app
```

旧的 `scipal_bench` 在观察期不删。
