## 一、检索层

### 1.1 UnifiedRetriever

**文件**：`services/search/unified_retriever.py`

#### `__init__(rerank=True, routing=True, ...)`
- **参数**：
  - `rerank: bool = True` — 是否启用 Cross-Encoder 重排
  - `routing: bool = True` — 是否启用查询意图路由
  - 其他参数待确认（初始化时加载 HybridSearch、Reranker、QueryRouter、Diagnostics）
- **返回**：UnifiedRetriever 实例
- **异常**：模型加载失败时内部 catch，不抛出
- **调用方**：`api_server.py: get_retriever()` 单例
- **可复用**：是

#### `retrieve(query, paper_id=None, top_paragraphs=6, top_figures=3, top_tables=2, top_papers=3, filters=None) -> Dict`
- **参数**：
  - `query: str` — 检索问题
  - `paper_id: Optional[str]` — 限定单篇论文内检索
  - `top_paragraphs: int = 6` — 返回段落数
  - `top_figures: int = 3` — 返回图表数
  - `top_tables: int = 2` — 返回表格数
  - `top_papers: int = 3` — 返回关联论文数
  - `filters: Optional[Dict]` — 过滤条件 `{section_l1, year_min, year_max, journal}`
- **返回**：Dict，包含 `paragraphs`、`figures`、`tables`、`papers`、`route`、`diagnostics` 等键
- **异常**：内部处理，不向上抛
- **调用方**：
  - `api_server.py: retrieve()` — `/api/retrieve` 接口
  - `qa_service.py: ask()` — RAG 问答
- **可复用**：是，这是核心检索入口

#### `get_diagnostics_report() -> Optional[Dict]`
- **返回**：检索诊断报告（如果 diagnostics 启用）
- **调用方**：待确认
- **可复用**：是

#### `to_envelope(query, paper_id=None, ...) -> Dict`
- **返回**：证据信封（envelope）格式
- **调用方**：待确认
- **可复用**：是

### 1.2 HybridRetriever

**文件**：`services/search/hybrid_retriever.py`

#### `__init__(use_online=True, online_max_results=30, use_protocols_io=True, protocols_io_max_results=10, verbose=True)`
- **参数**：
  - `use_online: bool = True` — 是否启用 NCBI 在线搜索
  - `online_max_results: int = 30` — 在线搜索每库最大结果
  - `use_protocols_io: bool = True` — 是否启用 Protocols.io
  - `protocols_io_max_results: int = 10` — Protocols.io 最大结果
  - `verbose: bool = True` — 是否打印日志
- **异常**：各子模块加载失败时内部 catch 并打印警告
- **调用方**：`api_server.py: get_hybrid_retriever()` 单例
- **可复用**：是

#### `search_papers(query, top_k=20, use_online=None, online_max_results=None, use_protocols_io=None, protocols_io_max_results=None) -> Dict`
- **参数**：
  - `query: str` — 搜索关键词
  - `top_k: int = 20` — 返回最大论文数
  - `use_online: Optional[bool]` — 覆盖初始化设置
  - `online_max_results: Optional[int]` — 覆盖初始化设置
  - `use_protocols_io: Optional[bool]` — 覆盖初始化设置
  - `protocols_io_max_results: Optional[int]` — 覆盖初始化设置
- **返回**：
  ```python
  {
      "query": str,
      "total": int,
      "local_count": int,
      "online_count": int,
      "online_in_local_count": int,
      "papers": List[Dict],      # 合并去重后按 score 降序
      "local_papers": List[Dict],
      "online_papers": List[Dict],
      "protocols": List[Dict],   # Protocols.io 实验方法
      "protocols_count": int,
  }
  ```
- **异常**：内部处理，不向上抛
- **调用方**：`api_server.py: hybrid_search_api()` — `/api/search/hybrid` 接口
- **可复用**：是，这是混合搜索核心入口
