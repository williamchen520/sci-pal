---

## 3. 理由

```text
work 是跨格式聚合单位
document 是格式版本
paper_documents 是旧 paper_id 到新 document 的桥
```

映射规则：

```text
work_id
  DOI 优先
  否则 paper_id
  sha1(identity)[:16]

document_id
  doc_<sha256[:16]>_<source_type>_<work_id[-8:]>

source_type
  filename .pdf -> pdf
  filename .xml -> xml

sha256
  实际文件内容哈希
```

同一文件、同一 work：

```text
只建一个 document
多个 paper_id 通过 paper_documents 指向它
```

这正是当前 7 组重复 filename 的处理方式。

## 5. 迁移

步骤：

```text
1. 新增 library_main.paper_documents
2. 计算每个 filename 的 sha256
3. upsert catalog.works
4. upsert library_main.documents
5. upsert paper_documents
6. 校验
```

原则：

```text
幂等
不重新解析
不删除 public 行
文件缺失则该 paper 跳过 document，不伪造哈希
```

回滚：

```sql
DELETE FROM library_main.paper_documents;
DELETE FROM library_main.documents;
DELETE FROM catalog.works;
DROP TABLE library_main.paper_documents;
```

P0/P1 新表为空时回滚安全；P2 前不做不可逆操作。
