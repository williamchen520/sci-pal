SciPal V33.96

SciPal 同时提供 headless API 与 浏览器工作台： 文献检索、综述、问答由 DSH 通过 MCP 调用；浏览器端可管理项目、实验、run、 签名与句子溯源。

句子溯源 输入 paper_id / sentence_id，查看页码、bbox、引用与图表。 双栏对比 并列阅读两篇论文（依赖本地 PDF）。 项目与实验 创建项目、实验、run，并查看修订与审计。 综述写作 生成大纲、综述草稿、引用与 Markdown 导出。 文献监控 按主题/期刊追踪新论文，生成周报并反馈。 领域包 查看术语、限定条件与证据规范。

DSH 工具：search_evidence · get_context · verify_answer · watch_run · ask_question · generate_review
