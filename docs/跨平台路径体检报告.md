## 5. 临时文件审计

### 5.1 PDF 三引擎

| 引擎 | 临时文件 | 结论 |
|---|---|---|
| Docling | 无显式临时文件；只读 PDF | 通过 |
| GROBID | 无显式临时文件；HTTP 上传 | 通过 |
| MinerU | `tempfile.TemporaryDirectory(prefix="mineru_out_")` | 通过 |

MinerU：

```python
with tempfile.TemporaryDirectory(prefix="mineru_out_") as tmp:
    out_path = Path(tmp) / "out"
```

Windows/Linux 都会落到系统临时目录，退出自动清理。

```text

```

`runner` 把临时文件放在目标目录，是为了 `os.replace` 原子替换，跨平台行为正确。

