# 证据落地校验（Grounding）

> 状态：实验完成，默认关闭。

## 1. 方法

`services/qa/grounding.py`：

- 将回答拆成句子；
- 每句必须：
  1. 带引用 `[P1]` / `[P2, P3]`；
  2. 与证据文本的词重合 ≥ 阈值；
- 不满足则判定 ungrounded；
- `SCIPAL_GROUNDED_ANSWER=1` 时直接拒答。

参数：

```
SCIPAL_GROUNDING_MIN_SUPPORT=0.5
SCIPAL_GROUNDING_MIN_RATIO=0.5
```

## 2. 验证

### 拒答题

4 个拒答题全部拒答：

```
q023 汞沸点   refused
q024          refused
q025 法国首都 refused
q026          refused
```

### 正常题 q001

```
coverage = 1.0
citations = 18
```

### 10 个正常题

| 阈值 | coverage | avg citations |
|---|---|---|
| 0.5 / 0.5 | 0.20 | 7.4 |
| 0.3 / 0.4 | 0.0833 | 2.2 |

说明：

- 收紧阈值能拦住拒答题；
- 但正常题被大量误拒；
- 词重合 grounding 无法区分“改写”和“参数知识”。

## 3. 结论

- 方向正确：证据落地校验是必要的；
- 当前实现不可默认启用；
- 需要语义级校验：
  - cross-encoder / NLI；
  - 或 LLM 逐句检查“是否被证据支持”；
- 不能只用词重合。

## 4. 语义级 grounding 试验

新增 `services/qa/semantic_grounding.py`：

- cross-encoder（bge-reranker-base）计算 claim ↔ evidence；
- `SCIPAL_SEMANTIC_GROUNDING=1`；
- 不要求每句都有引用，只看语义支持分。

### 阈值 0.2 / 0.5

- q001：通过，coverage 1.0；
- 4 个拒答题：4/4 拒答；
- 10 个正常题：coverage 0.2833（7 题被误拒）。

### 阈值 0 / 0.3

- 5 个正常题：coverage 0.6；
- 4 个拒答题：0/4 拒答（全部用参数知识作答）。

结论：

- 阈值高 → 拒答好、误拒多；
- 阈值低 → 正常题好、拒答失效；
- 当前 cross-encoder 分数无法稳定区分“改写”和“参数知识”。

默认关闭。

## 5. 下一步

1. 用 cross-encoder 计算 claim ↔ cited evidence 支持度；
2. 只对无引用/低支持句子重写或拒答；
3. 再跑 30 题 answer-level。
